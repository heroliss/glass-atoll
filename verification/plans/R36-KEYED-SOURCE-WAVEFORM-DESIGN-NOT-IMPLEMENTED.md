# 下一小候选：固定源时钟的不规则RGB曲线（本轮不实现）

已直接查看 `r36-radiant-normal-plus1p70-detail-hdr.png` 和 `...plus2p50...png`。长尾比R35清楚，但仍是规则、光滑、近等宽的白金线，带彩色头；不像大量粗粒子，也尚没有稳定的细小燃烧变化。PNG是显示相关截图，不是线性附件或绝对HDR/nit测量，不能从白芯直接断言FP16溢出或真实面板clip。

## 现有方程为何给出这个形态

- 各层source目前从点火峰值后到长平台/衰减只有少数近线性段。每个body只有life和原强度的轻微固定差异，缺少中途不规则变化。
- .88/.66/.40s尾是8个固定lag的Eulerian场节点；相邻节点间用归一化、连续的Gaussian线段核填满。adaptive曲线采样越充分，越不会留下离散“点缝”，这正是抗闪烁修复的结果，不能把正确积分关掉来伪造粒感。
- gold LUT随detached age改变色温，但各节点颜色保持单位Y，亮度仍是同一平滑source曲线乘固定指数冷却。它并没有模拟每颗微小余烬的不同寿命、反应或亮度脉冲。
- 半径.0018m在180m只是约.007px的world sigma，远小于.28px基础PSF；很多线的横向宽度自然相近。G16＋cameraEV14又可能经输出shoulder压缩沿线的可见差异。实际白芯成因需线性值/输出曲线证据，不能仅以截图替代。

原始研究只支持“燃烧强度可以起伏”这个方向。[JES2007论文](https://www.jes.or.jp/mag_eng/stem/Vol.68/documents/Vol.68,No.5,p.141-145.pdf)的Fig.3是特定光谱峰的仪器计数，正文讨论燃烧不均一和随燃烧面积下降的变化；其不是总RGB、cd、空中shell曲线或本项目可以直接拟合的噪声频谱。这里不会从图上的counts派生光度倍率、频率或制造参数。

## 仅做一项候选

未来新opt-in版本只替换**编译时生成的source RGB时程**，保留现有G16峰预算、life、点火/熄灭支撑、192根、3D运动/120m参考、.88/.66/.40尾迹、恒定头尾份额、物质/烟和音效。所有head、释放尾光、即时ledger、SH、local/cloud/GI自然采同一个不可变profile。不要在shader另乘噪声，也不把每帧random或固定lag索引当成真实粒子ID。

初始作者设置建议为seeded控制间隔.24–.32s、同一control段四个正插值子段；整个profile至多96 knots（含旧节点）。这是低频、连续的作者变化，不是严格带限的物理湍流模型，也不能宣称已模拟了真实微粒。

hash仅在创建时用新namespace＋eventSeed＋bodyID求值，不消费原native RNG。曲线直接用body-relative age查询；同一seed和物理相位始终相同。尾节点查询`sourceAge=now-birth-lag`，因此起伏属于释放时钟并沿尾场传递，不会粘在摄像机像素、frame number或lag bin编号上。

### 峰值与时间积分约束可以同时闭合

对当前各层恒定色度的source，令原归一化Y曲线为`b(t)∈[0,1]`。先在**用户倍率与G16之前**的不可变参考曲线上构造，避免U0时出现0/0或改变seed波形。

1. 合并原节点与新seeded节点，原life端点保持0。令seeded平滑值`m_i∈[.04,1]`；这里只存正的piecewise-linear knots，不在每帧生成随机值。
2. 设上包络`u_i=min(1,1.5*b_i)`，下包络通常为0。初始.12s、最后.08s以及原峰值节点可令`l_i=u_i=b_i`，保留原点火/终末相位，防止把淡出的内层重新点亮。
3. 对原eligible outer，在2.5s前后一个明确小保护区（例如±.04s，边界纳入grid）要求`l_i≥.1`，并验证`l_i≤b_i`。当前seed在2.5s所有outer的b为.416–.581，故存在余量。保护的是原own-peak10%几何门，不向未来未知profile泛化。
4. 定义节点`z_i(c)=clamp(c*b_i*m_i,l_i,u_i)`。新曲线是这些节点之间的线性插值，并用精确trapezoid积分求总Y。由于所有约束满足`l_i≤b_i≤u_i`：在c=1有`z_i≤b_i`，在c=25有`z_i≥b_i`。总面积是c的连续单调函数，故在闭区间[1,25]存在使`∫z=∫b`的解；可用有界二分或其分段线性断点求解，失败必须拒绝而非增加预算。
5. 再令`y=(1-a)b+a*z`，其中`a≤.8`。两个曲线已经同面积且同peak上包络，所以这个blend仍非负、峰不超1、总积分相同。根据实际knots的斜率选择固定a，使新增变化`|(y-b)'|≤2/s`，或作者选择更慢的界；实际a和实现后RMS必须写入metadata。这样单帧60Hz新增变化≤约3.33% own peak，不是帧间随机闪烁。

当前三个layer色度近似恒定，源标量面积守恒在实数算术下也保持RGB面积；实现仍必须独立核对三个RGB通道的binary64积分、derived I0、实际knot maxima与误差，不能把理想证明冒称已逐位实现。任何构造后的最大值以实际不可变新profile重新计算；既有上界不能沿用一个未验证的更小值。

恒定头尾份额及归一化延迟核不变，因此未裁剪参考域的head/tail全寿命积分也随原source闭合。空间接触、遮挡和透射会按新时间分配改变可见图像能量，不能宣称整幅图或物理焦耳守恒。峰值仍不超过既有derived I0，故不是第二个光度gain。

### 固定相位的调制度预期

以下是`r36-waveform-design-headroom.json`读取实际旧曲线得到的设计余量，不是已生成新波形或已经看到的改善：

| age | 原outer / middle / inner normalized Y中位数 | 新曲线上包络中位数 |
|---|---:|---:|
| .70s | .898 / .926 / .866 | 1 / 1 / 1 |
| 1.70s | .745 / .814 / .657 | 1 / 1 / .985 |
| 2.50s | .502 / .725 / .0698 | .754 / 1 / .105 |

外围在2.5s保留最低.1门。未blend的其余节点下限可到`.04*b`；a≤.8后实际最低约`.232*b`，斜率限幅会进一步减小变化。设计目标是在中段得到约15–35% source-relative RMS不规则变化，而不是新的逐帧频闪；该目标不是论文测量或当前验收结果。实际构造若只有几乎不可见的调制度，也不能只靠CPU通过就称改善。1.7/2.5s近景白芯可能仍压缩这种变化，最终必须同固定相位看线性值与HDR/SDR结果。

## 实现前后的最小门与成本

- CPU：旧profile exact；每seed/body/userU0/1/64波形身份稳定；原RGB各通道积分、peak、life/support/材料CDF、2.5s outer门和原几何不变；重复/乱序查询与暂停时上传字节相同；不得增加新source或暗中改变烟量。
- 仍N8时outer lag间隔=.11s。新增斜率界2/s意味着单个lag cell内新增Y最多可变化.22 own peak，不能据此宣布N8已收敛。需在固定实际phase、点火/末端和noise转折窗口比较N8/16/32的参考通量与空间分布；不要先放大N导致4m配对CPU回退。
- GPU attributes与draw核不变，但CPU窗口函数当前逐bin扫描全部emission knots。若3段变成约95段，192×9rows×8bins的最坏区间检查从约41,472增至1,313,280/更新，约32倍；缓存的静止帧不是动态成本。必须记录创建时成本、实际CPU更新时间与完整SourceT/SH/整帧成本，不能称“只改曲线所以免费”。这是下一阶段候选，当前dense GPU预算和正常原生帧门仍优先。
- 不改变物理时间/相机/曝光/天气来挑有利图；在同seed、同.7/1.7/2.5s分别比较旧和候选。局部颜色图像改善也不代替原生动态性能、source cache一致性和最终照片感。

本轮只完成视觉否决与具体方案/设计余量，不新增生产波形，不变更已冻结R36 source，也不执行浏览器或GPU。
