# R2：主动反证与跨模块审查

2026-10-26，研究中。这里记录真正改变候选方案的反证，不把“多审一遍”当作结论。R3定案前不改运行时。

## 已被推翻或收紧的假设

| R1假设 | 反证/失败条件 | 处理 |
|---|---|---|
| 升8K星图就能得到小星点 | 原图本身是绘制的星点，不是传感器PSF；更高清仍保留其角尺寸 | 改研究官方去亮星银河层+真实目录星点；目录缺口和PSF/曝光明确建模 |
| 当前日期已驱动真实天空 | 太阳艺术坐标与天文方位约定不同，月亮仅30秒步进 | 真实模式共享UTC/地点与统一世界向量；太阳艺术模式显式分开；月/日连续插值 |
| 给当前cube一个EV标签就够 | 六面逐面更新可能混着不同UTC/曝光，单scalar不能修复一张已混合的数据 | 双cube+冻结捕获快照/曝光、完整发布、cube和PMREM分别有标签；物理天空变化和存储曝光变化分开 |
| 预曝光变大就刷新全部环境 | 若仅为烟花储存headroom改变，物理天空没变；重画六面是无谓峰值 | 只做存储尺度补偿；物理天空revision决定刷新/中断；大UTC跳变才走一致性重建 |
| 固定夜晚21EV+限定两发即可避免溢出 | 自由飞近产生1/d²增长，Y归一的蓝色最大RGB更大，多星叠加仍可溢出 | 接受统一存储预算方案B，stored preEV与摄影exposure是两个变量；不能靠末端clamp |
| 真实火焰半径足以解决整个HDR范围 | 半径只消掉点源近场奇异；多个有限高辐亮度源叠加仍可能超HalfFloat | 采用有限源+最大RGB并发预算，逐缓存曝光元数据；测极端同屏/近景/暗星下溢 |
| 黑体温度可以生成全部真实烟花颜色 | 饱和蓝/绿主要是分子发射，不是任意黑体；教育页还存在CuCl₂简写问题 | 金白炽热连续谱与CuCl/SrCl等带发射分开；混色在linear；不假装一条谱线能完整预测实物 |
| 同时画火星、加点光和写环境一定更真实 | 同一镜面路径可能双计数，短爆闪进入慢PMREM会残留 | 显式路径归属：粒子源像/平面反射，限额局部漫反射/体积项；不烘入长期天空 |
| 普通透明材质加入主场景即可 | 主颜色alpha已用作water/leaf分类；透明烟/火会污染标签，并被旧时域拖尾 | 候选第四R8 reactive附件，先于分类读取并对有效reactive像素失效历史；还要保护倒影/受爆闪照亮的receiver |
| 把粒子透明度原样写mask足够 | α=.001但HDR强度10000仍有明显亮度，R8可能量化成0 | 单独定义保守二值/覆盖响应；用实际材质混合、MSAA resolve验证，不能靠源码推演 |
| 仅主粒子reactive即可 | 水中倒影、闪光照亮的叶/沙也快速变化 | 水用保守活动爆点反射范围或反射响应路径；接受更大旁路范围但不可泛关全部水面稳定 |
| 增加flash shadow只需一个sampler | 本机片元上限16；当前水路径约16个有效采样源 | 候选将near/far两个云影缓存保持原尺寸与精度合成2层sampler2DArray，腾一个单位；必须GPU核对实际active samplers |
| 把云/太阳深度塞同一half-float图最省事 | packed RGBA8高位深度与HalfFloat云透射精度/过滤完全不同 | 拒绝；不因省sampler损坏原4096太阳阴影。若用atlas必须保留精确tile/guard并算复制成本 |
| 关闭TAA就必然省掉其MRT成本 | 当前三附件仍分配/写入，开关只关resolve分支 | 不虚报带宽节省；五档按实际资源/消融差异定案 |
| 删除低档火星即可保持玩法 | 总能量、轮廓和颜色经tone map后都会变 | 保持逻辑头部/事件不变，优先只降轨迹/烟雾采样；其他LOD要证明能量和结构一致 |
| 发射前拉近镜头可解决看不见 | 违背第一人称投掷、自动镜头与右拖争用 | 默认从相机按鼠标方向真实抛物线；查看落点与烟花构图均显式可取消 |

## 本机能力证据

[LIVE-CAPABILITIES-R1.json](LIVE-CAPABILITIES-R1.json) 来自实际正在运行的WebGL2，只读采集：片元sampler16，draw buffers/attachments8，uniform vec4上限1024，纹理16384，RGBA16F/R16F/R8均列出8/4/2/1样本，float color/blend扩展可用。这只证明分别支持，**尚未证明四附件同绑、特定混合/resolve与完整着色程序组合通过**。

名义主颜色/运动/叶深度由18到19 B/sample（不含深度与驱动开销），R8有带宽/内存成本，不称免费。水面采样器预算来自静态路径计数，实际编译可能剔除未用uniform；以实际程序活动采样器及渲染结果为准。

## R3前必须闭合的问题

1. 统一辐射/曝光接口、预算上界与缓存元数据（天空front/back、PMREM、GI、反射、时域）；超预算的恢复顺序。
2. 真实目录与去亮星银河资产的来源/许可/大小，目录完整范围和已知空缺。
3. 十类首发机制、落在干地清空区的发射器尺寸/位置、轨迹范围与镜头包络；实拍长曝光偏差不被误抄。
4. reactive mask与反射/receiver保护的具体约定；实际混合测试不能被“mask看起来白”替代。
5. 候选五档哪些项必须等待消融后接受，默认第三档如何保留固定采样与原来稳定性。
6. 时区/UTC、真实与艺术太阳、日期跳变、暂停/隐藏、自动构图/手动打断的单一状态责任。
7. 真实烟花声音的可取得/可分发原录音与试听检查；若只合成不能冒充实录。

首发十类候选为牡丹、菊、柳、棕榈、环、心、分裂十字、闪星、扇形彗星、近地花束，详见烟花研究；仍需综合定案，而非已完成效果名单。
