# 初生烟核的减速扩张：有界数学反审

2026-10-27。仅数学设计与离线数值反例；未改运行时、未操作浏览器、未做视觉准入。针对 root 提议的正质量 Gaussian 状态模型，与环境 Taylor/Brownian 扩散、热浮升分别记账。

结论：**可作为一个很窄的、可关闭的初生烟核运动学候选**。两标量记忆能精确推进并合并同时间常数的这部分二阶矩；建议采用下面等价的非负 `B,Q` 存储，避免两个大数相减。它不是压力/夹卷求解，不会自动消除平滑团块；等向方差较大时还会把烟缕变圆。没有可据以校准所有源 `v0,τ` 的实测数据，不应先承诺改善或指定统一几立方米体积。

## 1. 明确 r 是什么，并核对原公式

令 `a≥0` 为这份烟物质自释放后的年龄，`r0≥0, v0≥0, τ>0`，`b=v0τ`、`R=r0+b`、`q=exp(−a/τ)`：

```text
r(a) = R − b q
r′(a) = v0 q ≥ 0
r″(a) = −v0 q/τ ≤ 0
r²(a) = R² − 2 R b q + b² q²
```

在该 Gaussian 合同里，`r` 应叫**一个轴的初生核标准差 σ**，单位 m；`v0` 是 σ 的初始增长速度 m/s，不是可见烟界、冲击前沿或颗粒平均平动速度。等向 Gaussian 的 RMS 距离为 `sqrt(3)σ`，当前渲染的5σ支撑也不是物理硬边界；整片密度仍无界。若想输入“肉眼半径”，必须另订等浓度/质量分数阈值，不能把其数值直接代入 σ。

从当前年龄推进 `h≥0`，令 `e=exp(−h/τ)`：

```text
A1 = 2 R b q                 [m²]
A2 = b² q²                  [m²]
Δs = A1(1−e) − A2(1−e²)    [m²]
A1new = e A1; A2new = e² A2
Σnew = Σ + Δs I
```

这恰好是 `r²(a+h)−r²(a)`，不是近似积分。`A1,A2` 不是质量或能量，演化不增减归一化 Gaussian 的 M。

**SPD 与单调条件：** `A2≥0, A1≥2A2` 可保证所有 `h≥0` 的 `Δs≥0`。出生构造有 `A1−2A2=2bq[r0+b(1−q)]≥0`；同 τ 推进/正质量平均保持此域。因此已有 SPD `Σ` 加非负倍数单位阵仍 SPD，原非对角项及特征向量保留。不要对任意外部 `A1,A2` 仅检查非负：例如 `A1=A2=1` 在小 h 下给负增量，可能破坏 SPD。

**“减速”不等于协方差斜率减小。** `r′` 严格减小，但 `d(r²)/da=2rr′` 在 `b>r0` 时会先升高。纯说明反例 `r0=.3m,v0=3m/s,τ=.5s`：σ 最终1.8m，初始方差增长率1.8m²/s，在 `.2554128s` 升至3.24m²/s 后才下降。这不违背半径减速，但不能把 UI/说明写成“方差增长率从出生起不断减速”。若强行要求后者，应另选模型或施加 `b≤r0`；不应为了措辞偷偷限制候选形状。

总体核也还包含环境项：简单单节点每轴实际宽度为 `sqrt(r²(a)+Daxis(a))`，不等于 r。Taylor 的环境方差斜率从0爬升，Brownian 则从出生已有 `2K`；因此这一分量的减速并不保证复合宽度速度全程单调下降。必须检查完整 Σ 的实际尺度/影像，不能只展示 r 曲线作为最终动态已符合的证据。

## 2. 等价且更稳的两标量记忆

建议记 `B=A1−2A2≥0,Q=A2≥0`。用 `u=−expm1(−h/τ)`、`e=exp(−h/τ)`，全是非负运算：

```text
Δs   = u (B + Q u)
Bnew = e B + 2 Q e u
Qnew = e² Q
```

新释放时直接构造 `B=2r0 b,Q=b²`；已龄化 a 时直接构造

```text
qa = exp(−a/τ); ua = −expm1(−a/τ)
B(a) = 2 b qa (r0 + b ua)
Q(a) = b² qa²
pastIncrement(a) = ua (2r0 b + b² ua)
```

不要从非常接近的 A1、2A2 再相减得到 B。有限输入、`B,Q≥0`、`τ>0`、`h≥0` 和协方差/记忆数值上限应在变更前验证；非法输入显式拒绝。`h=0` 不改状态。很大年龄记忆下溢到0表示有限扩张已完成，不代表烟质量消失。

这是由两个指数衰减构成的精确半群，任意分帧与一次推进相同（实数算术）；它与20Hz固定 tick/分段风积分可以独立组合。短 h 的 `expm1` 形式无需靠 `1−exp` 消减，也不需把很小正增量钳成0。

离线设计核查：20,000组正参数，`r0,b∈[1e−8,1e3]`、`τ∈[1e−4,1e3]s`、`a∈[1e−9,1e4]s`、两段 h 各在 `[1e−10,1e3]s` 对数取样。将 `Δs,B,Q` 的分段/合并差除以 `max(1,|Δs|,|B|,|Q|)`，最大 `6.43e−16`；增量最小0。此为公式的 Float64 设计检查，不是生产状态回归或 GPU 结果。

## 3. 同 τ 合并闭合；跨 τ 不闭合

同一物理时刻、共同 τ，采用现有质量权重 `wi=Mi/ΣM`：

```text
Mbar = ΣMi
μbar = Σwi μi
Σbar = Σwi [Σi + (μi−μbar)(μi−μbar)ᵀ]
Bbar = Σwi Bi; Qbar = Σwi Qi
```

未来增量对 B,Q 线性，所以合并前后该**独立、零均值核扩张的二阶矩加项**完全一致；`r0,v0,释放年龄` 可不同。不能从最老 birthTime、平均年龄或合并后 trace 重建这两个记忆。协方差矩闭合并不表示密度峰、细结构、射线 τ 或散射源逐像素相等，仍需已有合并误差诊断。

跨 τ 的未来是多组不同指数，不能一般压成同一对记忆和一个平均 τ。反例：两个等质量、同中心、`r0=b=1m` 的新团，τ 分别1s/10s。选择 τeff=1.8181818s 可匹配初始方差斜率，1s 后真实平均增量 `.931599300m²`，单 τ 代用为 `1.025071842m²`，约高10.0%。相同最终增量、匹配一个时刻或一个导数都不足以证明闭合。

**最小合同选择：** 一个 state 固定一个 `expansionSeconds=τ`，不同源种类仅变 `r0,v0`，未启用的包用 B=Q=0。不要假设当前同 optical profile 就意味着同 τ：`pyro-smoke-state.js:100–105` 的同 profile 合并可跨 source。若以后确需 launch/burst/star 各自 τ，须有限 τ-bank 的每组记忆或禁止跨组/显式容量退化，不能静默平均；这属于额外范围。

现有确定性均值/热状态只取平均，仍不存位置—速度及热/速度方差。不同浮升速度的两团未来会分开；新的 B,Q 不能恢复该缺失项。已有反例未来 y 方差损失 `.1548181217m²` 仍成立。同样，若把扩张改成导致包均值径向运动/不同风剪切，而不另存相应交叉矩，上述“共同漂移下加项闭合”证明不再覆盖。

## 4. 过去段 GL5 与当前源码的精确边界

`pyro-smoke-source-moments.js:26–32` 先把过去最多.30s的5个正权重节点分别输运/龄化到共同 end，再合并完整空间矩。未来候选应当：

1. 每节点物质释放时间为 ti，`ai=end−ti`；不是星的 body.birthTime，不是整发 burst 年龄。持续燃烧几秒后的新烟也从新释放年龄0开始。
2. 节点本征基础为当前 `sigmaPerp² I`。只再加 `pastIncrement(ai) I`，并保留已有 Brownian/Taylor 环境项；均值、真实过去轨迹、风积分、热龄化保持不变。
3. 正质量权重合并该节点的 `B(ai),Q(ai)`；同时保留目前的完整 covariance 合并。不得把每节点记忆重置为新生值，不得只上传记忆而漏掉已发生的扩张。
4. 进入 state 后从这个共同 end 推进。队列中的未来 release 仍不能提前龄化。不同源 r0 应来自源的本征核标准差；不能用整个路径的 `sqrt(traceΣ/3)` 倒推。

**禁止“对现有整个 Σ 乘 r²/r0²”。** 当前 Σ 已含轨迹 between-mean 协方差和环境扩散；该乘法会把已真实长成的路径长度/扩散再按爆胀倍率放大，改变均值路径的二阶尺度，混淆三种机制。正确独立加法对应卷积/独立零均值展宽的假设，不是同一份热能被严格分配给压力、夹卷与浮力。

未来接点仅是 state 的接受/推进/merge/publicPacket/snapshot（`pyro-smoke-state.js:49–57,122–134,145`）和上述源龄化。当前 CPU 列积分与 GPU 同用最终 Σ；无须新 shader 属性、质量变化、I/RGB/P 或 RNG。Taylor q 保持独立，`τexpansion` 不能冒充现有 `lagrangianSeconds`。这段文档没有实施任何接点。

## 5. 形态与物理自反驳

- **可能更圆，不是更多细节。** 对 `diag(9,.09,.09)m²` 的细长核，加 `3.15I` 后标准差长短轴比从10降为1.93649。它不旋转轴，也不制造涡卷/边缘高阶结构。现有光场还用 trace-isotropic 近似，扩大 Σ 也会改变其空间平均照明；不能把变亮/变暗单独归因于体积变化。
- **质量正且恒定，不等于可见度恒定。** 孤立等向 Gaussian 的峰密度随 σ⁻³、穿中心无限列密度随 σ⁻² 变化；增大 σ 会稀释，但与光源距离、相函数、深度/遮挡叠加后的视觉未必更自然。它也不会修复“所有星同一时间释完烟”的源时序问题。
- **受限的运动学代理。** `v′=−v/τ` 给出一个衰减速度尺度，但没有压力、冲击/声速、温度密度状态方程、夹卷或内部动量/能量守恒。冲击前沿不是烟颗粒包络；不能把 `v0` 取冲击速度，也不能称 shock CFD。BIRCO 官方爆压说明只支持区分传播压力扰动与残留介质：[Science of Blast](https://blastinjuryresearch.health.mil/index.cfm/blast_injury_101/science_of_blast)。
- **源种类不能一个体积定律。** 高速燃烧 effect star 留细颗粒轨迹并快速冷却/稀释；中心爆药、地面发射和星尾有不同起始动量/温度/材料。原研究支持分开释烟而不提供本站统一 r0/v0/τ：[Keller等2021](https://onlinelibrary.wiley.com/doi/10.1002/prep.202000292)。Taylor/Brownian 仍是另一类环境 spread，不能当初生 pressure/jet expansion 的校准。
- **小时质量滞留与寿命预算分开。** 记忆耗尽不会删烟；此模型不新增沉降、逃逸或 lifetime fade。长时 PM 证据不表示白烟团一小时等浓。若另做性能淡退，须单列可见性/质量账本与误差合同，不藏在 B,Q 衰减中。

## 6. 值得怎样证伪，而不是默认准入

只建议一个后续 opt-in 单因素候选，默认 off/旧源全输出精确；先固定一个全局 τ 和源种类幅度，不同时改 M、K/TL、source 时间分布/数量、光照或 renderer。参数是作者情景，未获观测校准。应从 r0/v0τ 导出的 σ(t)、5σ尺度和视图占屏量审查，而非先挑看着漂亮的数。

数学门：非负参数/SPD与非法域拒绝；0档完整默认反演；半群、30/60/120Hz同时间输入、GL5出生龄化及跨龄合并；不同 τ 拒绝/隔离；热交叉项反例保留；现有 rayT/GPU 读取同 Σ。对 δt 极小、大龄下溢、r0≪vτ、v0=0、near-zero σ 和容量强合并均给独立反例。

视觉门：相同实际 event 与 accepted camera/C/P策略/天气，在 release后 `.05/.15/.3/.7/2/10s` 同相位截图和≥5s连续视频。检查是否真从快到慢、是否由细缕变棉球、是否.30s源格出生造成节拍；不以“更淡”代替形态验收。CPU/GPU density 与未改源的质量账本须相同；烟包数不变并不证明填充成本不变。

资源门：仅每包2个 CPU Float64 数的数学下限为16B（4096包64KiB，不含 JS 对象开销），原时钟/20Hz推进。没有额外 shader 纹理/采样器/新 packet，但屏幕 proxy 面积会随Σ增大；当前保守半径 `5sqrt(traceΣ)`（`pyro-smoke-renderer.js:153`）可能增加 overdraw/fullscreen fallback。必须实际量测，不保证0 GPU成本。若只得到更大的平滑球而没有符合参考的初生变化，应拒绝候选，不能靠噪声乘密度补救。
