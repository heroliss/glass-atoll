# R3 定案：真实夜间岛屿、烟花与观察系统

2026-10-26。R1候选、R2反证与R3管线交叉审查已完成。**本文件是进入实现的方案；还不是功能完成或测试通过声明。** 用户已明确：本项目只作个人非商业用途，可使用署名星表。当前运行时尚未修改。

## 取舍结论

1. 使用统一UTC/地点的真实天球，另保留明确标名的艺术太阳模式；分离天文、物理、适应与音频时钟。
2. 保留固定几何采样和既有叶/水稳定算法，不重新引入逐帧随机采样。
3. 接受存储曝光P与摄影曝光C分离的全链方案B，拒绝用固定21EV硬乘所有新发光体或末端clamp掩盖溢出。
4. 烟花/烟采用有自身有限距离的独立效果层，不混入现有只看opaque-depth的TAA/空气/景深链。
5. 反射改为黑底透明覆盖率、最后补入真实天空的premult组合，既修复透明烟花丢失，又释放水材质一个采样器；**不先迁移整套云缓存到array**。
6. 星点采用目录/银河分层，而不是单纯把4K全星图换8K。离线实测表明8K有改善，但仍有较大星斑，且与4K不是简单保通量重采样。
7. 五档默认第三档；先固定候选、再用消融与压力实测筛选高成本项。低成本且有明显正确性价值的项各档保留，不以删灯/删物理事件降低画质。

## 共享状态与职责

每帧先生成一致的 `FrameSnapshot`，下游不能各自重新猜UTC或补曝光：

```js
{
  simulationSeconds, simulationDelta, adaptationDelta,
  utcMs, observer: {latitudeDeg,longitudeDeg,heightM,northYawDeg},
  celestial: {sunDirection,moonDirection,moonPhase,angularRadii,physicalSkyRevision},
  photometry: {storageEV, cameraEV, sceneRadianceScale, sourceBound},
  weather, wind, qualityEffective
}
```

- `worldUTC`支持日期、一天时间连续滑杆、速度/暂停和纬经度；UI明确民用时区/UTC，不把经度当时区。真实模式统一北起顺时针，旧艺术方位用adapter，不能直接沿用旧az数值。
- `simulationSeconds`驱动海浪/树/烟花/投石/星闪；UTC快进或倒放不加速这些物理过程。全局暂停冻结观察状态；单独暂停天文时钟不暂停海。
- 用户EV、夜间自动曝光偏好、HDR峰值/参考白分别属于摄影/显示域；切时段不偷改这些偏好。灯的“夜间自动开”属于显式策略，时间只影响其实际输出，不覆盖手动开关。
- 视角、天气、时间预设分别只改所属状态；组合摄影/演出按钮必须明确是组合动作。手动输入立即取消自动镜头意图，不删除已发射物理事件。

## 统一光与缓存

使用可追溯的有效场景参考标定，把cd/照度、源辐亮度和场景线性量换算放在一个模块。参考太阳lux只是工作标尺，既有天空/材质并未因此变成绝对测光仪。颜色、强度、源尺寸、路径参与标志分开储存；sRGB输入先解码，分子谱/炽热连续谱在linear中混合。

`storedRGB = physicalRelativeRGB * 2^P`，显示前使用 `2^(C-P)`。预算按**最大RGB通道、可见有限源面积/PSF、重叠、照亮receiver和多条光路**估计，预留有限余量；不能只按Y或launch时距离。P可以为负，C不被工程P静默改变。需要测试暗部下溢与最终可见弱星的误差；不以“Float32运算有限”代替所有HalfFloat附件有限。

环境使用两只256 FP16 cube：冻结同一物理天空/天气/密度相位/捕获EV，写back完成再发布front；cube与PMREM各有captureEV和时刻。scene P仅因局部爆闪变化时，只做采样比例补偿，不重捕天空。UTC连续变化不等于每帧离散revision，不让back job一直被取消；以跳变/物理误差阈值/捕获年龄决定刷新。大UTC/地点跳变以受控整轮刷新保持一致，明确过渡延迟。

GI缓存物理Float32系数后统一乘scene P，或等价地明确captureP；TAA历史带historyP，只缩放RGB，深度/age不缩放。大不连续时失效，常规P变换优先补偿。平面反射是当帧P，不给天空/物体/火星各乘不同倍率。

## 有限距离效果层与水反射

主链选为：**不含烟花/烟的场景 → 叶/水时域 → 有限空气 → 主薄镜头DOF → 有限效果合成 → 全场一次微散射 → SMAA → HDR/SDR**。现有Bloom要迁移，不能另叠第二个。暗角覆盖所有源一次。

效果每粒子/短段有真实view-depth、有限空气路程、有限源PSF及一次CoC/快门积分，核须归一。主效果目标只有颜色，允许采样原opaque-depth手动遮挡/软交界；不写深度假装烟是实心墙。火星和烟按足够细的远近顺序统一premult-over：

```text
emitter: RGB = T(0,d) * Le, alpha = 0
smoke:   RGB = T(0,d) * Ls + alpha * S(0,d), alpha = 1-tau
blend:   ONE / ONE_MINUS_SRC_ALPHA
```

Ls已包含烟自身opacity/散射积分，不能再乘一次alpha。纯发光不另加S；烟要补回被alpha-over误减的前景空气。不是两个“整组先火后烟”的固定画序。

反射capture清成 `(0,0,0,0)`，不画天空，opaque对象写A=1，透明效果保持premult覆盖。最后水面：

`reflected = reflection.rgb + (1-reflection.a) * skyReflection(R)`。

不unpremultiply，不因A=0丢发光RGB。RGB与A同一套mip。删除水着色器对uReflectionDepth的依赖，**包括旧debug13分支**，才真正腾出sampler；RT本身的depth保留。镜像效果用硬件depthTest且不绑定/采样当前附着depthTexture，避免feedback loop。镜像相机只负责投影；空气从镜像射线的水面交点P到源X积分，camera→P由主空气处理一次。

快速照亮的receiver和反射区域采用第四R8响应mask（或经过实际等效夹具的更小表示）；它先于旧alpha分类抑制历史，保留当前/上一帧范围。独立效果层自身不进旧TAA。R8加入合法MSAA交集、验证四附件同绑与resolve；所有非响应材质明确写0。优先保证正确性，不能以删除mask漏掉receiver换性能成绩。

边界明确：原opaque反射物的P→物体空气仍有既有近似；镜面/透射景深不是全路径薄镜头，DOF默认关。分层遮挡/单一resolved深度和深度排序有误差，需近景/烟前后/镜面实看，不能声称全谱路径追踪。

## 灯光与烟花

三盏实体低位灯安装在干沙上，候选高0.12–0.22m，有遮光罩、支架和磨砂透镜，默认暖白。以低位洗亮树干/沙地的实际射束构图，避免只在地上放三个发光点。分别调亮度、颜色、开关，可联动；物理位置不随画质变。

手电随镜头平滑跟随，具有光束软边、有限射程、距离衰减和有限阴影预算。标准材质、水面/水下沙床、近空气分别接同一局部光字段；原水路径16个采样器已实测上限16，优先使用反射改造腾出的槽给单手电阴影。不默认给每盏灯做六面点阴影。

可见灯数、逻辑发射源不随质量删除。烟花采用限额局部光聚类照亮地面/烟/水下床面；个体火星反射由可见源像处理，不重复添加同一镜面源。局部聚类不是逐火星光追，也不谎称进入原太阳专用多次GI。

烟花首发十类：**牡丹、菊、垂柳、棕榈、圆环、爱心、分裂十字、闪星、扇形彗星、近地花束**。形状、速度分布、拖尾、分裂和时序必须不同，先以同色比较，不靠换色凑数。红/绿/蓝/黄、金白和真实混色依据发射谱与实拍；不开放任意幻想色相随机。炽热金尾与分子色焰采用不同谱/衰减，输出仍受色域、曝光和白芯影响。

发射器在岛上远离树冠的干沙舌区，候选约(29,7)，实际要检查地形和树冠界限。实体管组随仰角/方位旋转；默认高仰角朝外海，手调/自动方向只影响后续发射，不倒转正在飞的弹体。空中主要高度约75–170m、低空20–55m是当前小岛的作者编排，不冒充实拍逐类测量。重力/阻力/风、燃烧/余烬/分裂固定seed与物理秒，30/60/120Hz结果一致。

自动表演按序让十类可辨，初版最多两发主要空中事件并行，额外请求排队而不删除现有能量。自动构图是独立可取消选项，按岛屿+预计爆点/轨迹包络和当前镜头FOV拟合，不强制改变时刻/天气；用户输入立即接管。

声音从发射、爆裂、哨声/噼啪分别调度，按实际源位置、距离、温度声速和听者位置处理空间化/延迟；尽量采用许可清楚的真实录音，再做距离滤波/包络。CC0 Single Firework预览/原件能否取得、底噪和剪辑需试听后接受；没有合格实录则明确合成，不冒称实录。暂停/重新开始要清理未播事件，不恢复时一口气补放所有旧爆响。

## 星空、太阳、天文时间

目录路线：明确出处/许可的Hipparcos光度/位置与Tycho-2，核单位/epoch/去重/波段；NASA去亮星银河层提供背景。亮星用与星等无关、积分归一的小点核，未解析恒星离线聚合保通量。采用同一分界避免漏掉中间星等或双加，源数据与派生资源分开保留。用户已允许非商业署名数据；元数据保留ESA/作者/CDS条款，不替整个项目凭空加许可证。

默认弱、连续相关的星闪，按高度/有效曝光平均；不每帧随机位置/亮度，不让银河整体闪烁，也不给日月盘相同scintillation。参数是物理启发模型，非当地实测高空Cn²。相对星等保100倍/5等关系；地面真实消光、月光/暮光、曝光影响可见性，不能一律点亮所有星。

日月同一UTC/observer，修正30秒月位阶跃；真太阳方向直接来自历表，真实几何与大气折射约定一致。太阳先隔离纯mask找方形来源，再采用稳定角距离SDF/局部固定积分，必要时仅边缘子采样，不重复整套天空march。核角半径、亚像素移动和通量，不把任何物理太阳缩成一像素后要求像素图案仍肉眼圆。

## 观察、投石与预设

保留WASD/方向键、QE/RF、Shift、升降、Home和可移动pivot。右拖积累目标姿态、按帧平滑，低延迟不做长尾漂移；失焦/结束清状态。普通滚轮明确为沿视线前后移动、中心同移而焦距不变；右拖+滚轮调漫游速度；焦距单独控制。界面显示对应说明/速度。

左键在未拖动时蓄力释放，按鼠标射线从相机前方发射真实有界速度的石子；左拖仍环绕但取消投掷，点选对焦/Alt中心等模式优先。真实弹道和连续地形/水面碰撞决定落点，不再“必中目标”或默认强制靠近。撞击质量/速度驱动水冠、环波/SWE与声音，保留近场可见尺度；有可选查看落点而非强制换镜头。

增加至少8个观察机位，另可朝当前日/月看；时间和天气分别有自己的预设。不能为追月偷偷改日期，当前天体在地平线下则如实提示。

## 五档与性能准入

默认“中”。候选主要轴为DPR上限/合法固定MSAA、太阳阴影2048..8192、海谱256..1024、云/近空气步数、焦散网格/更新、平面反射分辨率/样本；具体组合须在同一UTC/物理回放/镜头/天气/烟花下消融实测后决定。高档可研究更多云步数缓解低仰角欠采样，但不能靠把形状变稀少来做性能成绩。

固定采样、颜色空间/正确光学、源逻辑/轨迹/能量、HDR校准和摄影偏好各档一致。SMAA、稳定处理、微散射、低频GI等若收益小于噪声、或不构成明显关键路径成本，保留统一设置，不为“五档”硬切。火星头部逻辑数量优先不减；轨迹/烟的LOD也必须验证通量/轮廓/时间结构，不能只按N乘亮。

测多个预热后的12–20s窗口，包含日景、月夜/地灯、暗夜、手电近景、高覆盖与双发烟花。报告CPU/GL-GPU、rAF P50/P95/P99、最低滚动1秒和实际HDR提交，保留长帧；不把录屏fps/缓存暂停当运行fps。中档争取60、重效果/高档约30或更低可接受，质量与一致性优先于虚报保底。

## 实施分工与验证小步

- Root：main集成、曝光/缓存/局部光、finite-effects hook、water/lens/air/shadow、导航/投石；控制跨文件契约和回归。
- 天体：只改sky/night-sky及新天文控制/星图离线资产/相关夹具；不直接改main/UI。
- 烟花：新物理/渲染/音频模块、材质与轨迹夹具；不直接改main/water/lens。
- 界面/预设：index/style/ui与独立quality profile模块，按root接口接线；不擅自改renderer或全局曝光。

先做小型实际GPU夹具：有限源/PSF/混合、P等价与溢出、R8组合/历史、premult反射/遮挡/空气分段。失败先修基础，不堆完整表演掩盖。然后接一盏灯/单发/一个日期变化，再扩到三灯/十类/连续时间/全部预设。

实现后的每轮必须有“截图/连续片段发现的问题→原因证据→改法→同条件复验”，至少覆盖近中远、动态/暂停、HDR/SDR、景深开关、不同档。数值通过不代替实看实听。若关键亮度、烟花像不像实拍、声音质感仍无法自行确定，呈现具体短片/选项请用户验收；不会把未确定项写成已经满意。

本轮目标完成条件是全部授权功能可操作、关键光学/状态/性能夹具通过、参考照片与动态对照无已知严重违和、必要用户验收闭合、源码/资产授权/证据可追溯。有限成本近似要如实说明，不用“完美”替代证据。
