## 一手资料：近顶点是有根据的目标，引信不是vy传感器

[日本烟火协会《令和6年花火入門》正文p20 / HTML index22](https://www.hanabi-jpa.jp/booklet2024/pageindices/index22.html)把“玉の座り”良好解释为：打起的玉恰在上升至顶时开花。该页还把真圆展开、放射线状星迹及一致消退列为鉴赏条件。**这直接支持日本常见割物的近顶点开花审美/设计目标**；不等于所有地区、所有效果都必须在数学上严格vy=0，更不能因此认定这20图已经测到vy0。

[同册正文p17 / index19](https://www.hanabi-jpa.jp/booklet2024/pageindices/index19.html)说明尺寸、引信时程、开花高度和演出时机相关；[美国能源部说明](https://www.energy.gov/articles/5-facts-about-fireworks)也明确由起发时点亮延时引信、飞行中燃烧后触发开花。两者支持**预定延时配合弹道**，没有说使用速度传感器在检测到零速时点火。模拟可以用“近apex参考”求一组一致的发射速度和延时，再保持该产品profile，而不是每发实时等vy0后强行触发。

查得可靠的上升中效果实例是[协会正文p12 / index14](https://www.hanabi-jpa.jp/booklet2024/pageindices/index14.html)和[p15 / index17](https://www.hanabi-jpa.jp/booklet2024/pageindices/index17.html)中的昇曲：玉上升时带光尾/小花等附加效果，然后主花展开。**小花在上升中出现不等于主壳在明显正vy时开花**。本轮有界官方资料没有给出一个具已测正vy、可据此定量校准本图主burst的实例；不拿DOE的“上升中引信燃烧”改写成“主burst必在上升中”，也不拿未知曝光厂家照片证明速度符号。

## 大口径10+s：有厂商延时示例，但不能替图鉴定产品

2026-10-27直接读取[株式会社ライズ官方基础知识](https://rise-hanabi.jp/fireworks/knowledge/)“玉の大きさと花火の大きさ”图表及其原始alt；所列时间字段是**延時秒時**，不是星的发光life或整场show duration：

| 该表公称档位/直径 | 到达高度参考 | 图表延时 |
|---|---:|---:|
| 3号 / 9cm | 120m | 3.0s |
| 10号 / 30cm | 330m | 6.5s |
| 20号 / 60cm | 500m | 10.0s |
| 30号 / 90cm | 600m | 12.0s |

这是**厂商示例范围**，支持大口径长延时有一手量级依据，不是这发湖面烟花已证为60/90cm。协会相近尺寸的高度表也有不同数值，说明不能把一个商家的通用表当所有产品的实测标准。来源表没有逐产品阻力、初速、爆点速度或误差，因此高度+延时仍不足以确认实际vy。此处不复述现实装填/燃放/药量或安全距离操作资料；仅用于虚拟场景尺度研究。

还有一个不能跳过的运动学一致性反证：若把12s硬当作从muzzle到**vy0顶点**的精确上升时间，在无继续推力、向上被动阻力且g=9.81的模型中，从终点反向积分有`v(t) >= g(T-t)`，故`H >= g*T²/2 = 706.32m`；正上升阻力只会提高这一给定T的最低上升量，而非降到600m。于是不能把该行的600m和12s不加条件地同时绑定成“精确近apex flight实测”。这是模型/字段精度与参考高度含义的边界，不是宣称厂商实际产品有问题；额外发动机/不同触发计时定义/近似表值等也不能在没有资料时擅自补进去。长延时有来源，与“该组高度/延时已足够唯一反解真实弹道”是两件事。

## 对现有timed3候选与后续profile的约束

当前ring QA的`timed-reference/3s`在本站作者linear-drag .075/s模型、rise120m/80°下会留下约+21.5m/s的主壳上升速度；[此前CPU研究](../fireworks/RING-FLIGHT-HEIGHT-REVIEW.md)的计算本身仍成立。**这仅是所选模型下同时满足那两个参考数字的一组作者候选，不证明真实商用smiley都这样飞。** 若改变真实drag/参考高度含义/产品参数，结论会改变。尤其不能把该候选作为普遍“往上托住低尾”的默认补丁，以此回避过大的星速度离差、life/谱时程或profile高度不一致。

优先保留可回退的near-apex参考作默认/对照；未来单独选择一个有明确高度/飞行时长/口径来源的profile，输出真实参考t、burst vy、burst rise、整幅top/bottom-live范围。不用延长所有壳到10+s：本图不能据截图鉴定大口径，且既有120m小壳与600m示例不是一个尺度。若需新的near-apex延时参数，应该同时校准弹道而非仅改一个timer；不能一边锁旧初速一边强制新高度。

外层长金迹、彩色中/内层和16–17终末亮珠更接近[多层/时变发光profile方案](PYRO-TWELVE-SLICE-MULTILAYER-REVIEW.md)的缺口：现有head固定body RGB、age亮度衰减、尾固定thermal及少数window，strobe周期并不等于一次性终末flare。最小下一候选是在一个opt-in多层profile中声明末期发光/余烬阶段，沿用同logical body、clock、raw source账本/边界/照烟与反射；烟量独立，不因末期变亮新建一整发M。必须与固定色＋仅曝光露彩对照，不把所有截图亮度变化都拟合成新光源。

## 水反射与摄影边界

01–03反射较窄，06–12随红/黄/绿显色扩为宽的横向破碎亮带，近处有许多小facet亮点；后段随源退弱暗回。它支持同源发光时钟/颜色进入水的反射与有限空气路径，**不支持额外给反射独立加大gain**。大白核和宽光晕还混有曝光、镜头散射/失焦、视频处理；不能从SDR截图倒推出cd/nit、镜头PSF或真实水面坡度分布。

近发射点软烟块在06以后反复被不同源色照亮，16–17又随末期亮珠亮起来。这是“物质保留、照明改变可见性”的观察，不要求该烟自发光或随颜色改变材料。20图不是完整radiance计，仍需固定实际cameraC、同float master、自然安全P和事件/烟账本的受控模拟验证。技术通过与用户视觉满意继续分开。
