# 近龄烟源扩散：有限相关时间候选的独立审查

2026-10-27。研究与解析计算；未改运行时、未做视觉通过声明。

结论：值得做单因素候选。用有限相关时间替代从出生即采用长时间常数扩散率，有清楚的统计物理依据；`q` 能以很少状态精确推进一个受限 OU 二阶矩族。但是它不是任意位置/速度联合分布的闭合，也不等于经过校准的单次小烟团相对扩散。`TL=5–10s` 只能称作者候选。此改动不减少质量，并可能使局部烟更密、更亮；不能当作“烟变薄”修图。

## 1. 原始依据与当前差别

实际读了 Taylor 扫描原文 pp.205–209，包括 p.209 式(23)像素：平稳速度自相关决定位移方差，短时间方差按时间平方增长，长时间斜率恒定，且位置/速度交叉相关不能忽略。该文常被称 Taylor 1921；出版社书目列 1922，原稿 received/read 1920。指数相关只是其中一个具体例子，不是所有真实湍流的唯一形式。[Taylor 原文](https://courses.washington.edu/mengr537/Lecture_Notes/DiffusionContinuousMovements_TaylorDispersion_ProcMathSocLon1921.pdf)、[出版社 DOI](https://doi.org/10.1112/plms/s2-20.1.196)。

2021 年实际湍射流研究也区分短时 ballistic、长时 diffusion，并强调中间阶段依赖完整相关函数；这支持有限记忆的方向，不能为本场景提供海上 `TL` 数值。[JFM 研究](https://doi.org/10.1017/jfm.2021.325)。

当前源码的具体接点：

- `pyro-smoke-state.js:80,83,125–127`：`K=[.6,.12,.6] m²/s`，每次把 `2K dt` 加到协方差对角，从出生即长时间 Fick 极限。
- `pyro-smoke-source-moments.js:2,25–31`：5 个正 GL 权重代表过去最多 `.30s` 段，各节点先输运到同一 `end`，目前出生方差也是 `sigmaPerp²+2K age`。
- `pyro-smoke-state.js:52–55`：合并保留总质量、均值、完整空间协方差，但只存 `min(birthTime)`；它不是混合后扩散年龄。
- `pyro-smoke-state.js:68,139` 已明确：热/速度方差和位置—速度交叉项没有保留，合并后未来异质热分离不精确。新增 `q` 不可删除此限制。

## 2. 可封闭的受限模型：证明

以下是本审查从所声明 SDE 得到的推导，每轴独立；`K≥0,T>0` 在 state 生命周期固定。设随机扰动速度为平稳 OU：

```text
dU = −U/T dt + sqrt(2K)/T dW,   dX = U dt
E[U]=0, Var(U)=K/T, Cov(Xbirth,Ubirth)=0
R_U(s)=(K/T)exp(−|s|/T)
```

出生空间方差另外保留。年龄 `a` 的随机位移增量与交叉协方差为

```text
D(a) = 2K[a − T(1−exp(−a/T))]
C_XU(a) = K[1−exp(−a/T)]
```

所以 `D(a)=(K/T)a²+O(a³)`，`D′(a)→2K`。定义 `q=exp(−a/T)`。推进 `h≥0`：

```text
A = exp(−h/T)
ΔΣ = 2K[h − T q(1−A)]
qnew = q A
```

该增量非负，因为 `0≤q≤1` 且 `1−exp(−z)≤z`。它有精确半群：先 `h1` 再 `h2` 与一次 `h1+h2` 相同；没有帧率或分帧重置扩散年龄。

为何确实与联合 OU 相容，而不是凭年龄替代协方差？令 `S=VarX,C=Cov(X,U),R=VarU,B=T(1−A)`，一般 OU 的二阶推进为

```text
Snew = S + 2B C + B² R + Qxx
Cnew = A C + A B R + Qxu
Rnew = A² R + Quu
Qxx = 2K[h−2T(1−A)+(T/2)(1−A²)]
Qxu = K(1−A)²,  Quu=(K/T)(1−A²)
```

代入受限族 `R=K/T,C=K(1−q)`，恰好化成上面的 `ΔΣ,qnew`，且仍留在此族。因此 `q` 不是额外独立的神秘物理量，而是该族内交叉协方差的压缩编码。

同 `T` 的三轴可共用一个 `q`，`Kx≠Ky≠Kz` 不妨碍此结论。若各轴 `T` 不同，需要各轴记忆；若同 state 混入不同 `K/T`、非对角湍速相关或任意初始联合协方差，一个 scalar `q` 不够。

## 3. 过去段出生、合并必须怎样携带记忆

在共同物化时刻 `te=end`，GL5 第 i 份出生于 `ti`，`ai=te−ti`，质量归一权重 `wi`：

```text
qi = exp(−ai/T)
Σi = σperp² I + diag(Dx(ai),Dy(ai),Dz(ai))
μi = 当前已有的真实 root(ti) + ti→te 风输运 + 热浮升
qbar = Σ wi qi
μbar = Σ wi μi
Σbar = Σ wi [Σi + (μi−μbar)(μi−μbar)^T]
```

每份在共同 `te` 的随机扰动速度均值仍为零、方差相同，故混合随机部分 `C_XU=K(1−qbar)`。`Σbar` 按既有完整空间混合矩保存，随后使用 `qbar` 推进，**OU 随机扩散部分的未来二阶矩严格匹配未坍缩的 GL5 混合**。质量与已有确定性均值不变；不消费星 RNG。

严禁以 `exp(−meanAge/T)`、最老 `birthTime` 或新生 `q=1` 替代 `qbar`。指数凸性给出 `E[exp(−a/T)]≥exp(−E[a]/T)`；用平均年龄会把后续增量估大。当前方差还必须已包含每节点的 `D(ai)`，不能只加 `q` 而漏掉过去 `.30s` 的输运/扩散。诊断最早 birth 可保留，但不能再用于重建 `q`。

两包在同一物理时刻合并时，仍用原空间矩公式，并令 `q=(Ma qa+Mb qb)/(Ma+Mb)`。只要它们属于上述共同参数/共同均值速度族，就保留随机部分的未来二阶矩。热平均速度异质问题另计，见下一节。

## 4. 不能略过的反例

1. **不同速度均值**：两等量子团位置 `±a`、相对平均速度 `±v`。合并时空间 between-mean 方差 `a²` 正确，但真实后续项为 `(a+v h)²`；仅存 `q,S,meanU` 丢 `2avh+v²h²`。不同热浮升是现有源码中真实的同类近似；共同风的时间变化本身不会产生此项。不能把改造称完整 OU/热联合闭合。
2. **出生湍速被设为零**：若声明 `U(0)=0` 而非平稳随机采样，则

   `D0(a)=2K[a−2T(1−e^(−a/T))+(T/2)(1−e^(−2a/T))] ≈ 2K a³/(3T²)`。

   早期是 `a³`，不是本候选的 `a²`；跨年龄混合还需 `E[e^(−2a/T)]`，不能用 `qbar²` 替代。现有 `buoyantVelocity=0` 只表示确定性竖向均值，不等于随机湍速方差为零；这两者要在说明中区分。
3. **任意 X/U 初始相关、剪切、分裂/条件选取**：两个状态可同 `S,q` 而不同 `C`，下一步立刻不同。仅当 `C=K(1−q),R=K/T` 是不变量时，scalar 压缩才成立。不能声称从任意外部 packet 自动恢复这些隐藏量。
4. **单粒子绝对扩散不等于单次小团内部扩散**：相邻粒子会共享大涡，可能是整团质心游走，不能全算内部展宽。Batchelor 的原始研究明确把改变云团形状的相对扩散与固定原点扩散分开，并指出相对扩散取决于初始粒子间距。[Batchelor 1952 原研究/出版社摘要](https://doi.org/10.1017/S0305004100027687)。用本式作内部高斯宽度，是有效参数化；没有空间相关速度场，不能称复现了真实近源相对湍扩散。

## 5. 幅度和最小验收

只算一个孤立节点、初始各轴 `σ=.30m`，保持当前 `K`，尚未加星路径段的 between-mean 方差：

| 年龄 | 旧 σx / σy (m) | T=5s σx / σy | T=10s σx / σy |
|---|---:|---:|---:|
| .05s | .38730 / .31937 | .30050 / .30010 | .30025 / .30005 |
| .30s | .67082 / .40249 | .31715 / .30351 | .30878 / .30178 |
| .50s | .83066 / .45826 | .34500 / .30952 | .32366 / .30488 |
| 1s | 1.13578 / .57446 | .44987 / .33538 | .38477 / .31876 |
| 5s | 2.46779 / 1.13578 | 1.51568 / .72901 | 1.16977 / .58794 |
| 30s | 6.00750 / 2.70000 | 5.48679 / 2.46840 | 4.96865 / 2.23819 |

`σz=σx`。保持质量，1s 的 T=10s 孤立高斯中心密度约旧 **15.70×**，沿 z 中央柱光学厚度约 **5.32×**。这不是实际 48-root 场景预测，因为真实协方差另有路径长度、热分离与合并项；但足以反驳“只是无害细化/变淡”的表述。长时只保证斜率趋同，不保证相同年龄宽度重合；存在约 `−2KT` 的方差滞后。

建议仅候选开关，原模型精确保留。接受前最小证据：

- 解析式、联合 OU 矩公式、两段/多段时间半群三方一致；任意 `q∈[0,1]` 的 tiny dt 稳定、增量非负、SPD/质量不变。
- GL5 同一 `end` 混合与未坍缩节点的未来矩一致；30/60/120Hz、同刻注入、clear/未来 reservation 仍按真实时钟，不因改记忆重生旧烟。
- 混合不同年龄但相同随机均值的合并精确；异质热反例保留为已知限制，不写成通过所有联合矩。
- 同相机、同物理源/质量/阶段的真实画面 A/B；记录自然 P 和 HDR/τ 上界。更小协方差对 kernel culling、光照近源正则化与峰值预算都要使用同一实际 Σ，不能单独降低亮度掩盖。

数值上建议写成 `2K[h(1−q)+q T(z+expm1(−z))]`，`z=h/T`；极小 z 对后一括号用 `z²/2−z³/6+…`。这避免新生 `q=1` 时两个近等数相减。固定 T，不允许无重建协议地在存活包上切 T。

另执行了独立 Node 解析算术网格（`K=.12/.6,T=5/10,age=0/.05/.3/1/10,h=.001/.05/.3/1/8`）：半群最大绝对差 `1.78e−15 m²`，一般联合 OU 公式与 q 压缩式最大差 `1.78e−15 m²`，五年龄队列未来增量合并最大差 `8.88e−16 m²`。这只核实所列解析公式，不是生产模块或 GPU 回归。两等量、同位置、初始热速度 `0/1m/s`、共同阻力时间 `2s` 的反例，1s 后遗漏 between-mean 方差为 `.1548181217m²`，证明原热合并限制仍存在。

**决定：有条件支持研究候选；没有依据把 T=5–10s 直接认定实测海上参数，也没有证据它已解决黄团外形。** 只调整扩散时间律、不改 M/I/配色/光学传输，才有可证伪的单因素比较。
