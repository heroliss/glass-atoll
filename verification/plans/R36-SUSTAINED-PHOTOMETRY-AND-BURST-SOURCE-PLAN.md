# R36：持续星光、爆闪与环境受光

R35已完成三层参考尺寸。下一阶段仍以实际画面为验收依据，不把数学/编译通过等同于照片感完成。

1. 固定新尺度、seed、机位、摄影曝光和烟源，记录爆开后0–5秒的线性RGB、参考光度、发光面积、每条接收路径及源相位。优先解释+.70/+1.70/+2.50秒持续暗光、稀疏短尾迹，避免只为最初一帧加亮。当前1×仍是本站参考，未实测；任何新系数必须明确为作者参数。
2. 独立审查亮点数、头部发光和脱落余烬的寿命/亮度/颜色/时间积分。增加样式层次时，明确总光度、每点光度、每点烟量和总预算如何变化；保留旧样式和音效，不把复制点数当成无成本的细节。
3. 短时爆开光源另按[R35源合同](R35-NEXT-BURST-RADIATIVE-SOURCE-CONTRACT.md)设计，明确点火、上升、峰值、熄灭，统一进入可见光、镜面、完整光账本、烟、云、地表、水面和间接光路径。先不混改280米传播策略；以后逐接收面消除不一致，不能将双改收益归因于单个峰值。
4. 保持GPU完整源烟配对及当前显式容量；记录新增源跨64项边界的真实工作量，避免只估逻辑pair数。普通24团与QA逐点持续排烟分别验收，暂不无声替换默认。
5. 同物理时刻分别验HDR和SDR，之后看连续运动、曝光克制性、烟被下一发照亮、海面和岛面同步变化。截图不是绝对nit认证。保留用户设置、服务、机位和已认可主爆。

通过条件是持续阶段能呈现可信的层次、烟与周围物体的受光随源真实变化，并有相应整帧证据。CPU和GPU局部门只证明各自范围；若主观结果不能自信判断，再交用户查看验收。当前未实现本方案，整体目标 active。
