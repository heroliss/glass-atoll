# 本轮反馈验收：水、树影、闪烁与交互

2026-10-26，Windows / RTX 4060 Laptop / ANGLE D3D11。当前版本以本页和链接的最终记录为准；旧截图、旧失败与中途性能数据保留作迭代证据。网页仍运行在 http://127.0.0.1:5186/ 。

## 最后反馈的原因和修正

**水下树影原先确实缺失。** 自定义水体在折射海床命中点自行算光，没有使用 Three 的标准阴影路径。现按水折射率 1.333 回溯太阳光的入水点，查询实际方向光阴影图；海床直射、表面直射和体散射分别处理。天空环境与平面反射不被树影整块压暗。太阳转动和树木风动会更新阴影，高画质最多 60 Hz，流畅档 30 Hz，受实际帧调度限制。

实际图像 [69-underwater-tree-shadows.png](69-underwater-tree-shadows.png) 与 [70-underwater-shadow-visibility.png](70-underwater-shadow-visibility.png) 分别显示结果与海床遮挡调试层。CPU 光路与接线检查 **17/17**。这是平界面太阳回溯和足迹 PCF 近似，不是完整波动水面光线追踪或体积光束求解，见 [UNDERWATER-SHADOWS.md](UNDERWATER-SHADOWS.md)。

**叶片闪烁来自亚像素覆盖与历史拒绝。** 远处小叶比像素细，MSAA / SMAA 无法凭空重建漏采细节。本轮植被专用八点采样保持真实叶宽；GPU 序列夹具又复现了漏采立即清空历史、插值深度导致边缘误拒绝两处缺陷。修正采用最近有效深度与 R8 年龄元数据，最多桥接两帧漏采，保留深度、相机位移、遮挡和局部颜色裁剪约束。没有逐叶运动向量。

实际 GPU 单帧检查 **9/9**、连续序列 **6/6**；合成漏采夹具时间标准差比约从 .984 降至 .178，不能当作真实全场景闪烁下降 82% 的测量。实际风速 5 m/s、真实指针拖动已录制；抽样复核见 [AA-IMAGE-REVIEW.md](AA-IMAGE-REVIEW.md)。叶冠更连贯，但远叶会柔化、局部成暗丛，接触表不能排除几帧短残影，也不能证明完全没有闪烁。

**海面亮点闪烁属于高频反射欠采样。** 256 波随机方向谱场的 mip 保存高度、斜率及斜率平方，丢失的细波方差进入太阳高光与天空反射过滤；再加入像素法线变化和 1/120 s 统计曝光近似。它展宽直接太阳光瓣，不能称为全帧真实快门积分或完全消除闪烁。面板可分别关闭细叶稳定和海面高光抑制作对照。

## 其余反馈的实际处理

- **远海重复**：原 35 个全局波改为四级、共 256 个随机方向分量，每帧预计算四张 256² RGBA16F 场并生成 mip。周期 521 / 137 / 29 / 5.3 m；仍是有限周期模型，不是无周期海洋或 FFT。波谱 GPU 检查 **71/71**，包含解析参考、mip 能量、长时相位与状态恢复；旧误差模型的失败文件保留，见 [SPECTRUM-VALIDATION.md](SPECTRUM-VALIDATION.md)。
- **比例**：默认显著波高约 14.4 cm，5 m/s 风时约 22 cm；波长约 7 cm–52.1 m。浅水边界强迫从 4 s 调整至 20 s，西边界实际水深下浅水相速误差约 .72–3.99%。环波相速与群速分别约 .945 / .473 m/s。几何尺寸和理论核对在 [scale-audit-check.json](scale-audit-check.json)，不是现场测绘或完整能量标定。
- **叶片可见性**：实长 22 × 8.2 cm，放置选择可见、无遮挡水面，过远时靠近，提供定位圈与再次靠近按钮。桌面实测约 44 CSS px；390×844 / DPR 2 移动模拟中靠近后约 37 CSS px，面板自动收起，无水平溢出，见 [74-mobile-leaf-visible.png](74-mobile-leaf-visible.png) / [mobile-weather-leaf.json](mobile-weather-leaf.json)。长时间漂出视野是输运结果，不等于放置失败。真实手机未测。
- **水花**：25 mm 石子配薄水冠和 96 个约 .4–3.7 mm 的球形水滴替身，最长约 .45 s；亚像素滴按投影面积调整透明度，替代旧 55 mm 粗点。实际近景 [71-splash-macro.png](71-splash-macro.png) / [72-splash-macro.png](72-splash-macro.png) 和事件读回保留。透明水滴在焦散背景前仍较难辨认，未达到完整自由表面流体效果。
- **沙纹**：摄影颜色保持 2.14 m 比例，程序噪声和颗粒按屏幕足迹退到均值；避免远处不可解析细节持续计算和闪烁。检查 **12/12**，近景 FBM 差不超过 1.11e-16；深水非线性材质均值局部约有 1% 偏差，见 [SAND-FOOTPRINT-NOTES.md](SAND-FOOTPRINT-NOTES.md)。
- **云与天气**：新增湿度、温度、自动或手动云底、厚度、云量、风切变。露点与 LCL 关联云底，云量仍是指定的抬升覆盖参数；不解湿空气流体或预报天气。三维热泡和侵蚀、保守支持区、世界空间平流改善单一棉团形态。最后修正高频 detail 噪声错误的远距 mip 尺度，积分步数未增加；远边仍会柔化，程序云形与有限积分纹理尚可辨认，见 [WEATHER-NOTES.md](WEATHER-NOTES.md)。

## 最终验证

`npm run check`：21 个运行模块语法通过。`npm run verify:physics`：光学 **29/29**、水动力 **38/38**、镜头 **6/6**、自动画质 **40/40**。`npm run verify:details`：时间滤波 **20/20**、天气 **10/10**、支持区 520,704 个采样 / 0 误剔除、交互 **14/14**、尺寸报告、阴影 **17/17**、沙面 **12/12**。这些性质检查不等于画面已经达到实拍。

浏览器实际 GPU：波谱 **71/71**、时间滤波 **9/9 + 6/6**、隔离水动力 **12/12**。云密度 CPU / GPU 的 256 点对照中 130 点非零，最大绝对差 .003125，无非有限值；其基础 LOD 0 密度未被最后远距过滤改动。最终反射读回见 [reflection-feedback-final.json](reflection-feedback-final.json)，无非有限像素；2 个通道略低于零，最小约 −.0291，保留为数值边界，未宣称辐亮度处处非负。最终源与交付文件 SHA256 见 [feedback-source-manifest.json](feedback-source-manifest.json)。

实际性能采用原始 rAF 间隔和 GPU 查询，完整滚动一秒独立复算；最终远景、默认正午、云体可见视角与中途未达标版本分别记录在 [FEEDBACK-PERFORMANCE.md](FEEDBACK-PERFORMANCE.md)。浓云参数下仰视晴空缝隙的高帧率另列，不能当作浓云压力结果。平均和滚动一秒达到目标不表示每帧都在 16.67 ms 内，远景尤其仍有慢帧。

[约 14 秒实际音画片](feedback-immersive.mp4) 包含风动、真实拖动、放叶片和投石。两种媒体完整解码通过、音轨非静音且无 NaN / Inf；未将技术指标当作主观试听通过。视频早于最后远沙和云 mip 过滤修正，不能用它证明最终材质或性能；30 fps 转码也不能证明网页 60 fps。详情见 [FEEDBACK-AUDIO-VIDEO.md](FEEDBACK-AUDIO-VIDEO.md)。

交付默认环境声关闭、面板收起、正常渲染和波浪运行；[75-final-feedback.png](75-final-feedback.png) 与根目录 `preview.png` 为最终代码实际渲染。没有伪造 DLSS / RTX 开关；局部高度场求交、平面反射与 FSR 1 均按各自能力使用。当前最假的部分仍是程序云、远叶和近水交互的有限近似，未声称任意角度都无法区别真实照片。
