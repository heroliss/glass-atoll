# 金羽节奏、持续尾焰与银瀑下垂

本页为编排部分的 CPU 子报告。包含环境照明、最终 GPU 检查、三款实景回放与页面验证的完整结果见 [本轮验收](ACCEPTANCE.md) 和 [回放页面](review.html)。

2026-10-31。实施前已核对 `verification/choreography-polish/`，保留其中已有的 128 发四轮连续扫射、长寿命银瀑和对数渐暗。本轮仅修改 `complex-fireworks.js`、`complex-fireworks-style.js`、`complex-fireworks-motion.js`；三个完整原件位于 [before/](before/)。事件保留时间由主代理在 `fireworks-physics.js` 配套修改，主画面爆闪占比及环境受光另由主代理负责。

持续光源通过命名 `sustained-comet-v1`（上限 1.2 秒）及已有 `waterfall-filament-v1`（上限 2.2 秒）接入。未命名样式仍限制尾迹为 0.88 秒，构造与包络采样保持原值。持续光源在生命的 74% 处仍有 0.11 的相对包络，84% 处为 0.014，然后对数平滑渐暗；峰值、源 I0、尾迹分配比例和粒子数未提高。中后段光量有意增加，不声称发光积分守恒。

银瀑保持重力和 0.45/s 阻力。当前种子在常用 80° 发射时，子体生命 93% 处下落约 115–138 m；母彗星横向轨迹仍约 128.94 m。低角发射先用实际出生状态计算寿命，再为完整 2.2 秒释放尾焰预留最坏下沉余量，使源与尾焰在水平风合同下至少保持在世界 Y=1.03 m 上方。垂直速度下界为 `min(initialVy,-g/k)`，带重力和线性阻力的竖直轨迹至多有一个内部最高点，因而检查出生和终点加上最坏尾焰下落即可保守覆盖全时程。

实际 family/lifetime/tail 元数据同步更新：金羽身体上限 4.1 秒、出生延迟上限 12.7 秒；银瀑家庭身体时域 11.1 秒、尾迹上限 2.2 秒；其它复杂烟花尾迹声明上限 1.2 秒。主代理的事件保留修复按每体实际尾迹时长保留，另继续覆盖烟雾代理时域。

## 验证

[choreography-check.json](choreography-check.json) 为 **9/9**，脚本为 [choreography-check.mjs](choreography-check.mjs)。报告保存当前六份相关源码和本轮三个原件的 SHA256。

- 128 发方向、I0 与原件一致，仍穿过中央八次；实际最大发光身体并发从 24 增至 41，这是加快节奏并延长燃烧的成本。
- 两个持续命名样式的包络单调、有界、接点零斜率、末端归零；12 个未命名样式、3,084 个包络样本精确回归。
- 90 个银瀑事件覆盖 25/40/60/80/90°、tilt ±45°、roll ±30°及两个独立种子，共 17,280 个子体、432,000 个源/尾焰位置；最小世界 Y 约 1.03 m。
- 十种复杂烟花在仰角和水平风边界下的 121,355 个身体/尾焰位置被当前声明的空间包围覆盖。
- 十类事件均保留完整尾迹及至少 0.1 秒余量。银瀑本例真实尾支持至爆后 13.1365 秒，事件至 13.2365 秒。
- 实际生产 FW 的 CPU 属性路径在爆后 8.5 秒产生 1,493 条银瀑尾迹，917 条大于源 I0 的 0.001，单子体此阈值上的竖向尾迹跨度最高 27.34 m；旧裁剪时刻后 0.2 秒仍保留 97 条正尾光。没有调用图形上下文。
- 主爆与十二子爆的数量、锚定、出生时钟、峰值 I0 保持，更新后的 0.075 秒曲线及 0.04 m 半径单独验证。

`npm run check` 通过。既有 CPU 套件结果快照见 [existing-check-summary.json](existing-check-summary.json) 和 [existing-check-results/](existing-check-results/)：烟雾 **30/30**、自动光烟 **53/53**、全部样式 CPU preflight **12/12**、银瀑样式 **4/4**。旧几何 **1/4**、合同 **18/20**、包围 **10/20**、对数余辉 **5/6** 的未通过项全部为本轮明确改变的旧参数断言：19.05 秒扫射、同时头数不超过 25、5.6–6.1 秒银瀑、9.1 秒家庭时域、统一 0.88 秒尾迹或 0.18 秒闪光。没有修改这些历史断言；本轮新检查覆盖当前数值、完整尾迹和实际工厂。特别是旧包围脚本在 0.88 秒断言处退出，不能把它当成本轮位置通过证据。

## 限制

本报告是 CPU 数学和真实数据路径验收，未启动浏览器/GPU，不声称照片感、连续帧率或最终视觉通过。2.2 秒尾迹保留现有八个中点；最远中点 lag 为 2.0625 秒，元数据按完整 2.2 秒保守覆盖。中后段更亮、更长会增加实际合成负担，金羽并发也更高。

离地证明使用现有天气的零垂直风和世界水平海面，不代表任意垂直风或完整地形碰撞证明；现有运行时海面/地形可见性筛选仍负责实际遮挡。低仰角银瀑会缩短燃烧，避免延长寿命造成穿海。爆闪源已按约定变短变小，主画面“无白球、环境受光为主”的最终结果还依赖主代理的渲染份额和环境光实现。
