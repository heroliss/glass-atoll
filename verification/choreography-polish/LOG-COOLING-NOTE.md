# 普通火星的对数冷却收尾（第二版）

生产 `fireworks-physics.js` SHA256：`3b6f283cfb592763b86ad09fb7ff17f70bb7677b65d9b279eec1762badbee7d7`。首版 `66cf...`、原 7/7 报告、源码差分和说明完整保存在 `before-log-cooling/`；未改写它们。

仅替换普通、非闪星、非火箭标量火星的淡出因子。令 `q=clamp((age/life-.35)/.65,0,1)`，新因子为：

`F(q) = exp(-32*q*q) * (1-q)^2 * (1+2*q)`。

它不读取相机或显示器。原攻击项、指数基础项、身体寿命、I0、颜色、运动和源最大值均不变，没有补偿积分。32 是明确的美术衰减系数，不是温度、化学反应或实测坎德拉拟合。

在 `[0,1]` 内，`F>=0`，且 `F'=exp(-32q²)*[-64q(1-3q²+2q³)+6q(q-1)]<=0`。`F(0)=1`、`F'(0)=0`，`F(1)=F'(1)=0`。所以冷却因子在寿命 35% 处平滑接入，在末端平滑归零；完整包络末端也为零斜率。闪星保留完整旧包络及原脉冲算序，火箭与实验 `burnProfile` 分支不变。

`physics-cooling-check.json` CPU **4/4**：完整单块逆变回首版源码；20 类烟花的 40 个事件构造精确；10001 个冷却因子样本及解析单调性/C1 检查；31200 个闪星、603 个火箭、14400 个实验曲线样本精确。初次 3/4 的失败是独立导数公式产生 `-0`，测试误用 `Object.is` 要求 `+0`；只将“数学零”断言改成绝对值零，源码未为此变化。原脚本/报告保存在 `cooling-before-signed-zero-fixture-fix/`。

`physics-cooling-output-proxy.json` 另做 **56 次实际生产 FW CPU 属性填充、0 次 context 调用**。保留上传的 Float32 形状/颜色/8 快门包络值，然后用当前高斯像素积分、FP16 存储、应用相对曝光和 legacy fitted-ACES/HDR 输出公式计算隔离光点的横向阈值跨度。配置为 1209×1292、28 mm、36 mm film gauge、AA σ .42 px、快门 1/120 s、EV21、亮度 64 倍、单个真实笑脸外圈源，逐相位保持光点位于镜头中央，分别距 100/706 m。

在 .80 寿命处，新曲线中心最高 SDR 代码为 .34486 / .0015465，旧曲线两者仍为 1；新曲线 .85 已在本模型的 FP16/legacy 输出暗部阈值以下。末端快门仍会包含之前的微弱发光历史，这是现有 8 点标量快门合同，没有硬截断它。

这些数字是 **CPU 曝光敏感性代理**，不是屏幕像素读回、观感验收或 FPS。它使用 binary64 翻译 GLSL，包含 Float32 属性与 FP16 存储量化，但不模拟 GPU 算术、空气遮挡、重叠、光晕、DoF、vignette 或完整合成；连续横向代码跨度也不等于实际像素计数。EV21 是应用相对增益，非 EV100；1270 nit 仅沿用系统报告设置，非面板测光。实际 GPU 与实景观看由主代理另行验收。
