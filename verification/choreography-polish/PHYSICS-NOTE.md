# 笑脸、爱心与普通火星衰减

本轮只改 `fireworks-physics.js`；原件与 CRLF 字节已保存在 `before/`。当前 SHA256 为 `66cf244ea9ac4d1b2059a9ca762a6995a1806157729189dee46b48eb9fee73e4`。

- 默认 reference 笑脸由 120 点改成 72 点：外圈 46、两眼各 6、嘴 14。外圈和嘴用分层弧长位置，眼睛用填充圆盘分布。原 dense、spaced-mouth、compact-eyes 的身体数据、顺序和 RNG 消耗保持不变；其实际点数仍是原来的 120/144。
- 爱心由 144 点改成 64 点。先对原参数曲线建立固定 2048 段折线弧长表，再在每个等弧长区间内采一个固定种子点。它是折线弧长近似，不是解析弧长或真实烟花物理标定。
- 每个点的细微方向、深度、亮度和寿命差异只在事件创建时确定，不使用逐帧随机。相邻弧长参数间距保持在名义间距的 0.64–1.36 倍。爱心径向变化 ±1%；笑脸径向范围 .985–.999；两者局部深度速度不超过 .21 m/s。单点亮度仍在原生 5–10 参考范围，寿命仍在原来 `burn*(.88..1.11)` 范围内。点数变少后不补偿总亮度。
- 普通持续标量火星保留原攻击段和指数衰减项，收尾由最后 24% 改为最后 55% 的 cubic smoothstep。它在寿命末端以零斜率到零。旧曲线本来也是连续收尾；本次改善的是收尾开始较晚、视觉上衰减集中的问题。没有延长寿命，也没有归一化补偿发光积分。
- 闪星完整包络和脉冲算序、火箭包络、`burnProfile` 采样分支均保持。普通标量衰减的全局改动包括 powered-bees 中未使用向量燃烧曲线的 160 个原生点；不能声称所有旧烟花的亮度逐时刻都不变。

`physics-check.json` 为 CPU **7/7**：完整源码逆变恢复原件；其它八种普通烟花 48 个事件、1584 个运动状态精确一致；三个笑脸诊断布局 1224 个身体精确一致；680 个新身体在既有速度/寿命/亮度域内；查询顺序和 0/1/64 光学倍率不改变几何随机结果；5005 个收尾样本；9920 个闪星、402 个火箭、14400 个实验燃烧曲线样本精确回归。未运行浏览器或 GPU，也未作帧率或最终视觉验收声明。
