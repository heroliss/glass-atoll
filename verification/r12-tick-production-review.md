## Contracts implemented

- `createPyroSmokeTickState` accepts copied/validated emissions and wind, including same-clock inputs, into pending queues. `advanceFence` publishes a zero-time same-clock batch before subsequent full physical ticks. No birth is materialized early.
- One packet-array shallow clone per commit, packet copy-on-write, local input cursors, common-time graph/cache, and one publication point. Public packets/density remain committed and capped; private staging is bounded by `capacity + maxPendingEmissions`, with pending at most8192.
- Queries return copies and use separate weak kernel caches; they do not mutate the committed physical packets. Nested mutations are rejected before reading input getters.
- Each failed commit discards its private stage and retains accepted pending IDs/material. Earlier successful commits in the same advance remain. Invalid targets leave everything unchanged.
- `lastAdvanceSteps` and `lastAdvanceFences` report successful commits in the current valid-target invocation even if it throws. `diagnostics.lastAdvanceFailure` reports the attempted commit kind/end and retained committed time/progress. This declared diagnostic telemetry may change on failure; physical C/Q/ID/mass counters for the failed commit do not. Successful retry clears the record.
- Math starts from a pinned 8018-byte normalized-newline legacy extraction: validation, SPD kernel, density/finite-ray integral, mass sum, moment merge, sampled diagnostics, and thermal factors. Intentional validation differences now use bounded fixed-index snapshots: length is read once, exactly3/9 indexed components are copied once and validated, and custom iterators are never read or consumed. Arrays, typed arrays and indexed array-likes are supported; arbitrary iterable semantics are not. SourceId/albedo getters are cached once. Provenance verification mechanically reverses only these declared validation changes before comparing the legacy pin. The limits definition becomes an import and exports are added. No production source reading/eval/verification imports or cyclic fixture dependency.
- Graph source grouping uses collision-free JSON tuple keys instead of the legacy NUL delimiter. Valid identifiers containing NUL no longer alias another profile/source pair. This deliberately corrects that legacy corner; normal/native inputs retain exact same-fence parity.
