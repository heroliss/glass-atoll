# 近景矩形高光：PSF 审查与有界候选

仅修改 optical-bloom.js。原件保留在 bloom-before-gaussian/。未改变场景火光、曝光、HDR输出、镜头UI或其它生产源；未运行浏览器/GPU。

## 诊断证据与边界

已查看 near-before-bloom.png 和 near-before-no-bloom.png。相同附近光点在开散射时有明显轴对齐矩形晕边，关闭后主要是细白火光/快门形状。当前 down 核是可分离的 [1,2,1]²/16，四级逐半降采样；合成直接双线性采样四级图。这是正的归一化核，但支撑有限且以纹理轴排列；很高的线性辐亮度再经曝光/色调映射，会让通常很暗的紧支撑边缘显形。这与截图一致，尚不能只凭 SDR 图片排除全部 FP16 溢出或其它输入问题。

目标使用 HalfFloat、LinearFilter、NoColorSpace、toneMapped=false；这些设置适合这条线性HDR链。源码未见阈值或显式峰值裁切。ClampToEdge 需要单独注意传感器边缘，但不能单独解释画面内部光点四周的矩形。候选只处理光学散射核；不把原始白色长条/快门几何也冒充为 bloom 问题。

## 新候选合同

`createOpticalBloom(THREE,renderer,{quality:'gaussian'})`；省略第三参或明确 `quality:'legacy'` 仍保留旧核与默认。未知选项/无效 quality 在分配前拒绝。没有新UI或自动亮度阈值。

- 每级原降采样之后增加水平、垂直 Gaussian：σ=2个该级像素，半径12（6σ），25个正离散权重归一化。利用同尺寸 texel-centre 的双线性相邻配对，中心加左右各6对，共每轴13次纹理获取。相较 σ2/半径6 的3σ核，最外权重显著更小。
- 四级各一个同尺寸 scratch；实际13次渲染（4降采样+8模糊+1合成），不是5次。size、dispose、异常后的目标/viewport/scissor/READ framebuffer/XR状态恢复遵循原工厂合同。
- `.018` 总预算与 flare 启用后的 `.013/.003/.002` 分配不变；旧 down/combine shader 字符串完全保留，无阈值、无高光硬裁切、不另加能量。理想正归一化算子的峰值增益界为1；浮点累加、硬件采样、二进制16位存储仍需实际验证。
- 独立 Gaussian 的边界/中心权重比为 exp(-18)≈1.523e-8，二维角点相对中心约 exp(-36)≈2.320e-16。四级总PSF还含原降采样和双线性重建，不能把此单核比值直接冒充整个画面保证。所有有限核在无上限曝光下仍可能露出支撑；本方案不声称对无限HDR无条件消除边界。

## CPU 结果与尚未完成的 GPU 门

`bloom-gaussian-check.json`：7/7。覆盖25权重到13配对的代数、边界夹取、常量/黑场/居中RGB脉冲能量、方向性、正值和支撑、真实Three工厂的9个目标/13次惯性渲染调度、无读写反馈、异常恢复与销毁。默认/显式 legacy 的8种配置与归档旧工厂 shader/渲染命令轨迹严格相同。这里的 renderer 是惰性替身，不执行GLSL。

首次5/7原脚本/报告保留在 bloom-gaussian-check-before-fixture-fix.*：方向性比较门低于配对浮点计算的5.4e-13舍入差；资源测试遗漏了 Three.setSize 会调用 dispose 释放旧存储。只修正测试的128eps尺度门和“最终销毁恰多一次”的计数语义，没有为通过测试改变生产滤波算法。

Root 的后续实际共享renderer门应检查常量场、接近FP16上界的有限HDR脉冲、非负/有限/不增峰、完整图像预算（明确传感器裁切）、同半径角向轮廓与状态恢复，并分别计时 legacy5pass/gaussian13pass。实际图片是否去掉可见方晕、低灰是否被误抬和完整场景成本仍未测；通过前默认不提升。
