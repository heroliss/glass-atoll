# R31 SDR capture: source-only legality review

Decision: an explicit **single-sample RGBA16F default framebuffer → owned single-sample RGBA8 framebuffer**, COLOR-only/NEAREST blit, followed by RGBA/UNSIGNED_BYTE read from the owned buffer is a legal WebGL2 capture contract when `EXT_color_buffer_float` is enabled. This is specification review, **not actual R31 GL or numerical admission**. No context, browser, shader, production file or R30 artifact was changed.

Primary authority:

- WebGL's `EXT_color_buffer_float` exposes the native extension, apart from listed WebGL changes. Its readback restriction forbids RGBA/UNSIGNED_BYTE **directly from floating-point buffers**; that restriction does not apply once the read source is the owned normalized RGBA8 attachment. [WebGL EXT_color_buffer_float](https://registry.khronos.org/webgl/extensions/EXT_color_buffer_float/).
- The native extension's §4.3.3 amendment puts floating and normalized fixed-point color data in the same blit compatibility class. [Native EXT_color_buffer_float, revision10, §4.3.3](https://registry.khronos.org/OpenGL/extensions/EXT/EXT_color_buffer_float.txt).
- ES3 §4.3.3 permits differing compatible color formats and destination conversion. A normalized fixed-point destination clamps/quantizes. Multisampled source conversion has stricter format rules, so this contract requires actual single-sample source and destination. §4.3.2 guarantees RGBA/UNSIGNED_BYTE for normalized fixed-point read surfaces. Both framebuffer completeness checks and numeric-class compatibility are necessary. [OpenGL ES3.0.6, §§4.3.2–4.3.3, printed pp193–198](https://registry.khronos.org/OpenGL/specs/es/3.0/es_spec_3.0.pdf).
- A successful `drawingBufferStorage(RGBA16F,...)` establishes the effective default attachment format. This is the source-format authority; R30's contradictory default UNORM/8bit attachment-query metadata remains diagnostic. [WebGL drawing-buffer storage](https://registry.khronos.org/webgl/specs/latest/1.0/#DOM-WebGLRenderingContext-drawingBufferStorage).

Required implementation qualification before the one measured frame:

1. Existing healthy WebGL2; `EXT_color_buffer_float` available/enabled; effective `drawingBufferFormat===RGBA16F`, exact1209×1292 dimensions and compatible implementation RGBA/FLOAT or RGBA/HALF_FLOAT read preference. No format downgrade or silent fallback.
2. Bind default framebuffer for both READ and DRAW before source queries. Record/assert actual `SAMPLE_BUFFERS===0` and `SAMPLES===0`. Production's `antialias:false` constructor supports this expectation but does not replace the actual query. Sample count2 of the separate water-reflection target is unrelated.
3. Allocate an owned non-default texture with literal RGBA8/RGBA/UNSIGNED_BYTE; attach only COLOR_ATTACHMENT0. Require complete framebuffer, UNSIGNED_NORMALIZED component type, LINEAR attachment encoding and zero sample buffers. Record default encoding and reject unexpected SRGB interpretation: the intended operation copies already SDR-encoded numeric values and must not add a transfer-function conversion.
4. For capture, READ default/BACK and DRAW owned/COLOR_ATTACHMENT0; equal native rectangles, no scissor, COLOR_BUFFER_BIT only and NEAREST. Capture immediately after normal SDR lens output inside the same whole-frame query. Read the owned buffer only after healthy/non-disjoint completion, with PACK/PBO state explicitly normalized/restored.

The SDR artifact is deliberately clamped and quantized to8bit. Do not claim preserved out-of-range radiance, retained float values, HDR-display validation or bitwise identity with a separately CPU-rounded float capture. It needs **6,248,112 raw bytes**, versus24,992,448 for RGBA/FLOAT, before base64/string/report overhead. A failed qualification must stop; the separately selectable float contract would need its own explicit byte declaration, not automatic retry.

The smaller readback does not reduce scene pixel shading. Retain the reviewed143-draw/41-render/19,279,476-element/10-blit/5-mipmap/32-clear/100ms retrospective envelope and require fresh current-browser original rays. The existing CPU projector estimate of5,738,696 main+mirror proxy-pixel visits is an upper model, not a measured GPU duration. Native targets increase fragment and MSAA work even if geometry, optical source counts and18 numerical draws remain unchanged.
