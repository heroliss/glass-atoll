## Independent numerical reference

The CPU oracle evaluates erf by32-point Gauss-Legendre integration rather than the shader's five-coefficient erf approximation. It applies the actual Float32 attributes, projection uploads, source radius, shutter, spatial stretch and RGB bins to a pixel-integrated Gaussian. Adaptive paths use complete global positive midpoint sums, rather than copying the production per-pixel local subset clipping loop. Quad/viewport clipping is included.

The comparison reports finite/range/alpha status, maximum absolute pixel error, peak-normalised error, visible relative error, per-channel captured flux and flux relative error. Acceptance thresholds are absolute2e-7, peak-normalised.003 and per-channel flux relative.003. The tolerances include Float32 projection/interpolation and production erf/support approximations; they are small fixture gates, not a universal shader error proof.

The temporal profile's physical bin contents are deliberately supplied rather than generated by simulation. This tests the actual shader transport of those bins. Stage1/head/ember CPU integration fixtures separately establish their temporal profile meaning.

## Guard and restoration scope

Entry GL errors stop before any owned FW/texture/target creation. Shader/link/FBO/readback/GL failures stop all remaining fixtures. With a timer extension available, each actual draw is timed; a draw over25ms, disjoint result or unavailable result stops remaining cases. Bounded timer polls submit no additional draws. There is no new context or canvas resize.

The helper restores logical target/face/mip, logical and actual viewport/scissor, default/MRT DRAW selection, separate READ framebuffer and READ_BUFFER, PACK/PBO, clear state, output/tone/exposure, XR, shadow flags and shader-debug callbacks. Default framebuffer restoration submits exactly one BACK/NONE item even if the browser aliases all DRAW_BUFFERi queries. Owned objects are disposed before final physical-state restoration and verification. Entry/exit GL errors are included in the final result.

This is the listed-state contract, not a proof of all program/VAO/texture bindings. It does not test reflection, corner/near-plane/depth/DOF cases, source P bounds, changing smoke T(t), receiver exposure history, whole-scene visual quality or native FPS.
