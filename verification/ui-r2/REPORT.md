# 机位、烟花可见性与推荐性能方案

本轮按用户反馈修改了产品默认行为；旧组合预设和“无文字投石条”约定由本轮新要求替代。

## 具体修复

- 日/月机位原来从固定位置正对天体，太阳方位变化时会完全背向小岛。现在由天体方向选择观察岸侧，瞄准小岛。所有预设都检查岛上参考点，必要时少量调整瞄准点。13个实际浏览器预设全部通过岛屿投影检查；数值检查另有324例。投影检查不等于对每一片树叶的遮挡证明。
- 新增“岛边观烟花”，用当前所选烟花的真实米制包围盒与小岛共同构图，沿主图案法线观赏。普通牡丹约距岛190米，原远景约400米；不缩小烟花。随机偏角、其他样式或用户移动后，仍可能需要调整构图。
- 烟花快捷区增加“烟花观赏机位”。从岸边仰角很低的机位看不到高空花火，也可能是花火在画面上方；现在可直接切观赏机位。
- 实测白昼牡丹确实提交了224颗发光星，而不是按白昼时间禁用。旧基础强度仅5–10个参考cd，夜间曝光补偿掩盖了源功率偏低的问题。运行场景统一采用64倍作者亮度参考；火星、尾迹、照明与烟气照明账本使用同一来源，用户1×乘数及0×调试语义保留，运动和燃烧时间不改。默认底层工厂仍为1，供原基线检查使用。
- 这个64倍是视觉参考重设，**不是测得的实物烟花功率**。白昼花火对比度仍比夜晚低。单位定义可参见 [NIST光强单位说明](https://www.nist.gov/pml/owm/si-units-luminous-intensity)；不同烟火的实测色光研究见 [Characterization of display pyrotechnic propellants](https://www.sciencedirect.com/science/article/abs/pii/S1359431116316362)。这些资料不为本项目64倍数值提供实测标定。

## 烟气的明确取舍

| 模式 | 画面与实际工作 | 取舍 |
|---|---|---|
| 轻量短烟，默认 | 每次空爆最多18团既有半透明短烟，约8.5秒，使用簇光照；不更新长期体积host，不做光点×烟团透射 | 烟气较简单，不长期积累，光遮挡较粗 |
| 长期体积烟 | 原有随风、扩散、积累及源透射；细致逐源受光仍为单独实验开关 | CPU、GPU开销仍会随燃放与积累增长，未保证密集模式流畅 |
| 关闭 | 隐藏短烟并停止长期host模拟 | 没有烟气氛围 |

原先只关闭persistentSmoke时，后台仍在更新全部烟团。现在mode切换会真正结束旧烟尘epoch并清空烟气；重新开启长期烟只接收新发射的源，避免孤立旧burst与巨大追赶。音效始终接收完整事件流。清除短烟只抑制当前烟花的烟气，不删除亮点、尾迹或之后的新烟花。

长期体积烟代理范围5σ改为4σ，舍弃极淡外缘。1663团真实快照的双眼factory像素代理上界约减少32%；这只是填充工作上界，**不是总帧率提升32%**。显式5σ仍可保留，详见 `../R43-SMOKE-SUPPORT-IMPLEMENTATION.md`。

## 全场景性能排查与处理

| 部分 | 发现及处理 |
|---|---|
| 烟源/物理host | 约2,500团现场即使隐藏仍更新；推荐模式现在跳过这部分，改用短烟 |
| 光源×烟团透射/逐源SH | 复杂度随两者乘积增长，预算不足存在昂贵CPU回退；推荐模式不执行，完整模式保留并标注高开销 |
| 间接光照 | 高空烟花到地面的地形射线原来仍多次采样；利用同一高度网格上界早停，保留原采样结果及树冠透射。13,200条新旧工厂射线结果相同；高空样本地形查询56,368→0 |
| 水面反射/折射 | 水面多次场景捕获，镜像再绘烟/云/火星。中档反射边长改为0.75，取消反射MSAA；请求像素数为原56.25%，不代表整帧提速同幅度 |
| 主场景AA/阴影 | 推荐中档MSAA8→4，保留SMAA和时域稳定；阴影仍4096，保留较高档位 |
| 天空/云 | 中档云采样64→48；大气、空气透视和高级采样档位保留 |
| 波浪/焦散/沙滩/植被 | 检查更新和捕获路径；本轮保留512波场、既有焦散限频和植被稳定方案，避免为省时损失近景海面细节 |
| 环境立方图/PMREM | 已有分面限频、跨帧捕获与较低PMREM更新频率；本轮未加入重复缓存 |
| 镜头/输出 | temporal、空气透视、bloom、SMAA和HDR/SDR的完整链路计入实际整帧测试，未仅用粒子pass声称整帧达标 |

## 实测与边界

- 原现场：约2475–2490团、两枚活动烟花附近的4秒CPU profile，146帧，CPU提交中位26.6ms；烟花/烟源/音频段8.4ms，光度6.45ms。间歇GPU读数约12ms，说明不能把问题全归给GPU填充。
- 新推荐方案：原生1373×1292、中档、近岛烟花机位，5秒343个帧间隔，活动两发，平均68.23FPS；帧间隔中位13.4ms、p95 26.9ms；CPU中位12.9ms，GPU中位10.646ms。见 `profile-light-actual.json`。
- 两组是实际体验观察，**不是逐帧同一工作负载的单变量A/B**：机位、花火阶段、亮度、积烟量和推荐采样都有变化，不能把差值归因到某一项，更不能保证所有样式/长时间燃放稳定60FPS。
- 完整烟尘重新开启后新发射产生12团，关闭后归零；GL检查为空，见 `full-smoke-reenabled.json`。没有继续堆积数千团做危险的长时压力重现。
- 保留已通过的第三版主爆音频源码，SHA256 `4e5ede41813249f062e50b212553e5e1821c27feaead8416b68ab51ba1b8ec31`。
