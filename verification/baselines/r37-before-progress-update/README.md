## 水、尺度与光

水体使用 **IOR 1.333**、Snell 折射、精确介质 Fresnel 和沿太阳/视线两段光程的 RGB Beer–Lambert 衰减。折射光线用五次迭代与三维海床高度场求交；水下太阳阴影沿 Snell 光路回到**入水点**取样。焦散由折射光子足迹和 Jacobian 聚光得到，主要作用于海床。物体平面反射请求 **2× MSAA**，天空反射采样与背景一致的动态立方体环境。

海面由 **256 个固定随机相位模态**合成四个默认 **512² 半浮点 mip 场**，可选 256/512/1024；域宽 **1021 / 137 / 29 / 5.3 m**，波长约 **6.3 cm–69.2 m**，是 Fourier 合成而非 FFT。独立窄向涌浪峰周期 **7.5 s**、默认显著波高 **16 cm**，风停后仍存在；风浪峰约 **2.2 s**，与重力/毛细短波单独响应风。默认组合显著波高约 **18.8 cm**，5 m/s 时约 **21.9 cm**。相干传播与固定相位干涉形成波组，没有每帧随机噪声。几何、折射、焦散、叶片和声源使用一致的系统增益；mip 坡度方差与高光统计曝光也分别按增益平方合成。

长波与投石扰动由 GPU 小振幅浅水方程推进，背景长涌浪由 **20 s** 附近的三个频率组成，默认边界振幅 **1.5 cm**；近场环波区分约 **0.945 m/s 相速**与 **0.473 m/s 群速**。平均潮流通过水深加权压力投影绕岛流动，约束 `∇·(H U) ≈ 0` 与干岸通量。它仍是固定岸线、深度平均模型，不计算完整破波、上淹退水、垂向涡流或三维 Navier–Stokes；涌浪输入与海绵边界会交换能量，不宣称总能量严格守恒。

默认投石对应 **25 mm**、约 **21 g** 小石，蓄力初速 **5–22 m/s**，轨迹使用重力与线性阻力解析解，再与共享水面/地形连续求交。飞行时间和落点由初速、射线方向及碰撞面决定；不强迫相机靠近。水花由 **96 个球面水滴近似**和薄水冠组成，首组滴径约 **0.4–3.7 mm**、存续不足 **0.45 s**。叶片固定为 **22×8.2 cm**，沿平均流做 RK2 输运，叠加近似 Stokes 漂移与往复轨道运动，起伏取共享 GPU 水面；没有完整刚体水动力或 GPU 瞬时水平扰动速度读回。水花也不是体积、动量守恒的独立流体求解。

## 间接光、HDR 与阴影

有限漫反射面元从实际沙地与植被几何取样，缓存地形和多孔树冠可见度；一次/两次太阳反射进入 18 个 SH1 探针，2/4 Hz 更新并平滑过渡。原有太阳 Hemisphere 填光已移除，PMREM 天空照明保留；水下床面接受同一反照率与路径衰减。这组SH太阳漫反射缓存不占水 shader 的纹理采样器；手电阴影另有采样器，当前水材质实查为16/16。它是低频太阳漫反射近似，**不是完整水/天空/物体无限反弹、SSGI 或路径追踪**。

HDR 默认自动判断：须浏览器确认 WebGPU `rgba16float` / `extended` 且报告 HDR 显示能力；自动模式还要求完整系统亮度数据。Windows 本地只读接口取得每屏 DXGI 峰值、全屏峰值与当前 SDR 白电平，可明确选屏或手动覆盖。当前机器系统报告两屏 **700 / 1270 nit**、SDR 白均 **280 nit**，这不是其他设备的默认值，也不是测光仪实测。多屏自动匹配采用有来源说明的前台快照，并定期刷新；嵌入浏览器匹配不准时可明确选屏。

校准映射保持同源 SDR ACES 暗部与中间调，高光平滑、有界地扩展到所选峰值；纸白按 Windows SDR 白归一，再进行一次扩展 sRGB 编码。它不是原生 80nit 线性 scRGB 或官方 ACES HDR ODT，场景也未做绝对 lux 标定。首选浮点 WebGL → WebGPU 复制无显式 CPU 读回，PBO 为明确备用；缺失原生数据时显示回退来源，SDR 继续可用。普通 PNG 专门走 SDR 输出。详见 [当前 HDR 与证据](verification/CURRENT-HDR-SUMMARY.md)。

阴影为 **2048 / 4096 / 6144 / 8192** 四档，默认 **4096**，受设备纹理上限限制；光空间范围紧配固定树冠/接收地面，不随相机滚动。微量镜头散射在 HDR 中用归一化点扩散核分配 1.8% 辐射，不叠加无界发光。自动像素缩放默认关闭，开启后才按 60/30/24 帧预算目标调整内部尺度；这些是目标，不是实测帧率，也不锁帧。

## 天空、沙地与植物

天空实时计算球形大气的 Rayleigh、Mie 与臭氧消光，云层采用有限步三维体积积分、云影与有界散射近似。背景、环境光、反射和物体太阳色共享天空状态。温度与相对湿度估算露点/LCL 云底，也可手动指定云底；云量、厚度、高空风切变均实际控制云体。这不是完整天气流体、降雨或多次散射求解。

默认体积云在共同云底处从零连续增长，修正了正噪声偏移造成的密度硬跳变。修复仅影响最低5.2%的生长层；云团的整体形状保持当前模型。物理边界与实际GPU证据见 [云底检查](verification/plans/CLOUD-DENSITY-EVIDENCE-REVIEW.md)。

夜空采用本地 **HIP/Tycho星表点源 + 暗星通量聚合 + NASA无HIP/Tycho低频银河背景**与 **LRO月面反照率**。Astronomy Engine以统一UTC、经纬度和观察高度计算太阳、月亮、月相及恒星坐标旋转；时间加速只影响天文钟，波浪、烟花、风与声音仍按物理秒推进。默认地点 **4.5°N / 118.6°E**；预设时间、天气、视角彼此独立，手动太阳为明确的艺术模式。

星点使用同宽的像素积分PSF，亮星与暗星由通量而非尺寸区分，并对有固定物理频率的微弱闪烁作快门平均。目录的绝对V星等零点与有效场景参考转换有明确记录；银河背景另有显示标定，整体不声称肉眼或绝对光谱测光。用户已授权个人非商业用途，ESA目录及派生数据采用 **CC BY-NC 3.0 IGO**，署名见 [数据与声音来源](assets/credits.html)。

场景存储曝光 **P**与摄影曝光 **C**分开：所有源先按未曝光RGB包络预算P，输出补偿`2^(C-P)`，避免改摄影曝光时破坏半浮点精度。天空使用双cube同快照完成后发布，cube与较慢PMREM各带独立P/UTC标签及采样比率；时域历史也补偿P差。新源和湿度变化先重新预算再绘制，源强不靠最后钳制Infinity修补。

`aerial-perspective.js` 对相机到物体/海面的有限光程计算 **RGB 透射与入散射 `L·T+S`**，替换旧的固定颜色雾与海面独立 haze。空气系数包含 Rayleigh 与海洋气溶胶近似，RH 通过预设 κ 吸湿半径增长及面积比例影响 Mie 消光，并把同一增幅共享给天空与太阳色。朦胧度控制的是环境尺度，不是实测粒子质量；没有严格求解粒径谱、Mie 效率或连续光谱。空气以半分辨率有限步积分、深度感知重建，太阳源项可查询树/云遮挡；六个有界局部光源共享反平方/锥角与Rayleigh/HG相函数，手电使用独立阴影，局部源到散射点的空气消光仍为近似。背景天空旁路，避免重复消光。可见光束取决于光向、介质与遮挡，不保证每个视角都有明显光束。

沙地摄影输入仅为 **Poly Haven Sand 02 颜色图**，使用公布的 **2.14 m** 尺度；未使用包含人造压痕的原法线、粗糙度和位移图。代码生成颗粒法线、湿度与床形，颜色随机平铺和 mip/footprint 过滤减少远处闪烁；地表和折射海床共享反照率。非线性阈值过滤仍带来约 **1% 的远处深海床材质通道均值偏差**，不是全画面的误差比例。

椰树采用分层树干、叶柄与羽状细叶风动，同步更新几何、法线和阴影。薄叶透光使用相对米制厚度、**RGB Beer 吸收、连续观察/光方向透射瓣及反射/透射预算**，共享实际太阳强度与树/云阴影；厚度、吸收系数为有效标定，没有标本实测或完整 BSSRDF/叶肉多次散射。叶法线 mip 的平均向量长度用于估计丢失方差，再加像素扰动方差过滤 GGX 高光；叶片几何、尺寸和叶脉未因此粗化。实际 GPU 已核对八张叶纹理的完整 mip 链、三线性过滤和各向异性，但纹理 mip 不能解决移动亚像素三角形的覆盖闪烁。

当前默认采用沿叶轴运输的局部截面，叶宽、数量、中脉及风锚点保持原尺度；更多叶面在低机位可见。阴影与间接光源采样在选择这份几何后建立。[12机位与GPU检查](verification/PALM-B0-ACTUAL-REVIEW.md)、[高清近景A](verification/palm-frame-b0/HD-legacy.png) / [B](verification/palm-frame-b0/HD-transport.png)保留对照。叶形仍有规整的梳齿感，这轮并未完成全部植物造型与材质的照片感打磨。

植被时域分支使用解析风动/相机运动向量、覆盖率及前后深度，并保留最多 **2 帧漏采 age** 的回退；没有任意模型动画的完整运动捕获。默认采用稳定的 MSAA 采样，**不加入人为逐帧像素抖动**。水面另有按标签隔离的 **25 ms 短辐射历史**，逐采样验证历史深度与类别，平滑高光/倒影/焦散亮度；没有水面完整运动向量，波浪几何和模拟时间仍正常推进。历史重建可能柔化细叶或留下短暂尾迹，可分别关闭。暂停 settle 后保留画面并按需重绘；相机、光照、天气或镜头变化会恢复绘制。暂停后的 rAF 计数不能当成持续渲染帧率。

这些是有限成本的实时近似，未实现全谱渲染、完整 SSS、完整 GI、树木弹性或空气动力学。Mip 按纹理语义配置：不能把深度、packed 阴影、数值状态与标签元数据一律开 mip 或直接平均。

## 地灯与烟花

三盏约17.3 cm的地表灯呈三角形分布在小岛西、东、北三侧，使用四周无遮挡的乳白球形扩散罩与金属底座。全向点光源向各方照明，保留独立颜色、亮度、联动与夜间/常开/关闭模式；手电跟随相机。原生PBR物体、水下海床、泡沫、薄叶背光和有限空气使用相同局部光参考，灯罩发光按球形投影面积换算；近场仍是点源近似。灯体接受太阳、月光和手电阴影，手电有独立有界阴影；三地灯与两个烟花光簇未实现完整源遮挡或局部多次GI。当前布局与近景见 [地灯实景检查](verification/ground-lamps-scene-check.json)。

十种烟花为牡丹、菊花、垂柳、棕榈、笑脸、心形、分裂、频闪、扇形与花束，实际轨迹、分裂、寿命和颜色有差异。笑脸为固定世界平面的120颗真实三维星体，侧看会自然压扁；不是朝向相机的贴图。空中品种按90/120/150mm产品参考分为120/160/190m爆高，指80°参考仰角下相对发射点的上升高度；低角度保持初始能量，实际高度随之下降。爆开宽度、星数和绝对光度尚未完成商业产品标定。参考实景与化学发光谱带制作近似RGB，不声称完整焰色化学、实测燃烧光度或CFD。最多两组活跃事件，额外发射排队；停止不凭空删除已发出的能量。

## 镜头、性能与验证

默认 **28 mm** 全画幅投影；可调 24–70 mm、±1.5 EV、f/1.4–f/16。自动对焦使用环绕中心，也可锁定手动米制距离，或点击“点选对焦”后选择物体/水面；`Esc` 取消，点选会开启景深。近距离、长焦、大光圈更容易观察虚化。曝光是相对控制，光圈用于实时薄镜头近似，没有绝对 lux/ISO 标定。

“自动运镜”可选缓缓环岛或环岛观赏烟花，一圈2/4/8分钟。后者按当前所选烟花的轨迹范围与小岛共同构图；改变发射几何或焦距后退出原构图，键鼠移动可立即接管，暂停会冻结镜头。“镜头光晕与鬼影”为默认关闭的可选项，与原有高光散射共用一次线性HDR PSF及1.8%预算；属于物理启发的虚拟镜头，不是实测镜头追迹。

[此前16秒环岛笑脸音画](verification/pyro-r2-orbit-preview.mp4)使用实际场景及当前混音，含新版三角灯、笑脸、环岛镜头与可选光晕。分钟级烟尘、烟花瞬态照云和新增局部间接反弹仍在独立验证，尚未接入此影片；下方旧24秒影片作为历史对照保留。

主链路为 **线性HDR四MRT/MSAA → 植被/水面时域 → 有限空气 → 主镜头DOF/暗角 → 独立有限距离烟花 → 一次共同Bloom → SMAA → 显示输出**。发光/烟使用预乘合成，水反射以透明黑背景存储，水面再补一次天空。动态光照与倒影响应mask绕过旧历史，防止发光拖影。五档请求2×/4×/8× MSAA，按RGBA16F/R16F/R8/深度的合法样本集合交集取值；所选档请求8×且设备支持时采用稳定的8×采样，低和较低档分别请求2×和4×。SDR 分支经 ACES/sRGB，内部尺度低于输出时使用真正的 **FSR 1 EASU + RCAS**；HDR 分支使用上述校准映射与浮点呈现，放大为线性采样，不冒称 HDR FSR。画布保持完整输出尺寸，`q=1` 绕过 FSR；WebGL 2 路径不提供原生 DLSS 或完整硬件路径追踪。
