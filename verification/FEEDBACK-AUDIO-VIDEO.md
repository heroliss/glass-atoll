# 本轮反馈片：音画技术核验

2026-10-26。检查对象为 [feedback-immersive.webm](feedback-immersive.webm) 和 [feedback-immersive.mp4](feedback-immersive.mp4)，事件记录见 [feedback-immersive.json](feedback-immersive.json)。本次重新运行 FFprobe、完整 FFmpeg 解码及解码后 `astats`；没有修改运行时代码或音视频文件。

MP4 是恒定 30 fps 的预览转码，不能把 417 帧当作浏览器录得 417 个独立画面的证明。原件实际解码为 402 帧；网页实时性能另看持续基准，本片导出帧率不能证明持续 60 fps。

四个 cue 均在本片时间范围内。已实看本片的 [接触表](feedback-contact.jpg) 和 [拖动区间逐 1/8 秒抽样](feedback-drag-eighth-second.jpg)：拖动段有连续机位变化，随后进入近水面观察叶片的景别。结合实际输入事件记录，这是本轮拖动证据。**没有使用较早的 `feedback-wind-motion` 作拖动证明：那次拖动 cue 发生在其录制结束之后。**

录制后状态包含一片长 **0.22 m**、宽 **0.082 m** 的叶片、一次投石和对应波纹；声音已开启，两个实录素材均解码成功、`warnings:[]`，海浪包络为 `scene envelope`，采集结束后 `captureActive:false`、AudioContext 仍为 `running`。

## 完整解码与声音信号

对两文件分别执行 `ffmpeg -v error -xerror -i <file> -map 0:v:0 -map 0:a:0 -f null NUL`，结果均为 **exit code 0，错误输出为空**，完整视频与音轨均可解码。

对解码音轨执行 `astats=metadata=0:reset=0`，结果如下；单位为样本峰值/RMS 的 dBFS，不是 LUFS 或 true peak。

两条音轨均有有限、非零的峰值和均方能量，确认**不是静音轨，未发生数字满幅削波**。AAC 与 Opus 的解码样本数、尾部 padding 和时间字段不同，不能用压缩包或解码帧长度假称逐采样对齐。

## 范围与边界

这段约 14 秒的片段包含最终采用的选择性植被时域抗锯齿、水面阴影和新方向波谱，**录制早于最后一次远处沙滩 minification 优化和云噪声 mip 足迹修正**，因此它不证明那次最后优化的画面表现。

模型没有实际听到音频，本报告只通过了文件、解码、事件记录与信号检查，**不能称主观试听通过**。海浪录音来自美国南卡罗来纳州，叶声为通用素材，均非马尔代夫或仙本那现场同期录音；投石水花声与很轻的空气底风是程序声音。来源、许可和署名见 [声音素材说明](../assets/audio/SOURCES.md)。风量、相机空间关系与波面统计包络共同驱动混音，不是逐采样流体声压同步，也不是逐个波峰的精确声学重建。
