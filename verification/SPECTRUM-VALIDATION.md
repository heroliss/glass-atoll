# 四层波谱 GPU 验证

2026-10-26。最终实际 WebGL2 报告 [spectral-gpu-final.json](spectral-gpu-final.json)：**`passed:true`，71/71 检查通过，GL 错误 0、着色器错误 0**。验证器为 [spectral-gpu-check.js](spectral-gpu-check.js)，本轮只修正验证模型，没有为得到通过结果改动运行时波谱。

## GPU 波场与 CPU 数学基准

这是 **256 分量线性方向 Fourier 合成**，四个 **256² RGBA16F** 周期场，世界域为 **521 / 137 / 29 / 5.3 m**，通道依次为高度、x/z 坡度及坡度平方矩。显式波数、振幅与重力毛细色散提供数学模型；本检查核对实现一致性，不把它称为 FFT、真实海域测量或完整 Navier–Stokes。

- 四场全部 texel 扫描有限值、正负高度/坡度、平方矩及方差量化界。
- 每场取 **256 个相同 texel 中心**，以原始模态常数和 CPU 双精度计算高度、两个解析导数与平方矩。运行时刻 **298.285899999846 s** 的全部对照通过。
- 独立临时谱实例在 **30,000 s（8 小时 20 分钟）** 对照同一 CPU 基准，验证 CPU 双精度 modulo 2π 相位封装后的长时间结果。两次对照的最大高度误差分别约 **0.0396 mm / 0.0609 mm**，均在已记录的半浮/着色器误差界内。
- 高精度 sampler 拷贝与原生 `gl.readPixels(..., FLOAT)` 逐值一致；mip 1/3/6/8 的 texel 中心也与原生 mip 附件读回一致。四个域在 x/z 两轴整周期平移的最大差均为 **0**。

这些结果证明所检查模态、时刻和采样条件下 GPU 与 CPU 的数值一致性，不证明所有视角均无闪烁、无可察觉周期重复，也不替代 SWE、非线性破碎或视觉真实性验收。

## 驱动 mip 与精度审计

早期失败来自验证器的精度假设，不能据此判定源波谱损坏：

1. RawShader 的 sampler 原先未显式声明 highp；现已明确声明，并用原生读回验证。普通 Three ShaderMaterial 本身会注入高精度 sampler 默认值，没有因此修改运行时。
2. `THREE.DataUtils.toHalfFloat` 在本地 r180 源码中截断尾数，不能当作 GPU mip 的逐级 nearest 舍入基准。
3. 原先假定 mip 中间归约全用 FP32、最后才写回半浮；正负值抵消到接近零时，该假设给出的界过小。

最终使用逐值解析区间：FP16 正常数间距为 `2^(floor(log2(|x|))−10)`，subnormal 间距固定为 **2⁻²⁴**。独立通道量化造成的负方差按 `δw + 2|sx|δx + δx² + 2|sz|δz + δz²` 加原始点积的浮点误差界判断；mip 则把子区间平均、FP16 中间 lerp 与最终量化误差逐层传播，保留抵消前的误差来源。接缝比较使用局部双线性偏导、权重精度和插值舍入界，**不要求正常斜率下 ±epsilon 两点的值完全相等**。

这里的源格式中间精度模型是保守数值界，不能据通过结果断言驱动内部确实使用 FP16 ALU。8 位小数权重的硬件参考来自 [NVIDIA 官方线性过滤说明](https://docs.nvidia.com/cuda/archive/12.9.1/cuda-c-programming-guide/index.html#linear-filtering)，对本 WebGL 路径的适用性另用实际夹具检查，不冒称通用 WebGL 保证。

**独立于波场**的 64² exact-half 抵消夹具包含 **4,096 个标量比较**：旧 FP32-only 假设有 **153 个越界**，最大误差/旧界约 **19.7762**；源格式 lerp 区间 **0 个越界**，最大误差/界 **0.249994**。独立 2×2 ramp 的 **19,018 个标量比较**也全部在硬件过滤界内。实际谱所有 mip 的最大误差/界约 **0.319944**。这是对错误验证假设的独立反证，而非针对某一波场相位增加经验倍数。
