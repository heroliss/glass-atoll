# B1 CPU 预检：自然重算与逐段保长是两条不同方案

2026-10-27。**仅新增 verification 脚本、JSON 和本说明；没有改运行时，没有浏览器/GPU操作。** 已读 [B0之后计划](plans/PALM-AFTER-B0-PLAN.md)与 [interface 独立反审](plans/PALM-B1-INDEPENDENT-REBUTTAL.md)，并请 reference_research 复核重力/长度约束的数学边界。

结论：值得进入一次有边界的 GPU 候选，但建议先比较 **B0 / 45°逐段保长**，75°只作为较强对照，不能默认胜出。**自然直接重算不能作为“只改变朝向、实体长度不变”的最终候选**：虽然名义 L 完全不变，它确实使一些小叶的上传中脉弧长变化超过 10%。逐段保长解决的是这一个几何混淆项，尚未证明照片真实度、风动或性能改善。

- palm-frame SHA256：`df9471498cdd88c35e76c5d8855f2eec5ad401cb98856c4a9aadb63dc5dacf8a`。

脚本只在内存读取生产源码，插入不消费 RNG 的 latent collector，记录原 blade 的 direction、curl、droop、ridge/profile等输入；将原相对 helper import 解析为绝对 file URL 后以 data URL 载入。**先逐byte比对六组网格全部 attribute/index 与正常生产构造器，再使用这些参数。** 原公式重建全部上传中脉每个 Float32 字节也完全一致，不是凭名义 L 猜长度。0°两种算法均直接返回已选 B0 的全部 buffer 对象，不执行身份三角运算、不重算法线。

一次中间检查曾因 `bare+(total-bare)/2 === (bare+total)/2` 的浮点运算次序而失败；最后检查明确测量两个等价式的舍入差并要求 <1e-14 m，没有改 torsion 分布或放宽实际几何约束。JSON保留该最大舍入量。自然方案“弧长门槛不通过”作为独立 conservationAssessment 明确保留；22/22不表示自然方案通过不可伸长条件。

## 固定的扭转定义

198枚羽叶中只处理 **175枚健康成熟羽叶**；9枚幼叶、14枚枯叶、9枚枪叶、灌木、叶轴与鞘不改。31,162片羽叶小叶中，健康成熟的有28,168片，满足后半弧长条件的 **9,992片**实际受影响。

用原解析 rachis 曲线的弧长 s(t)，固定原最早小叶根的 s0 和整轴 S。令 a=s0+(S−s0)/2，施加 `theta=A*smoothstep(clamp((s−a)/(S−a),0,1))`，A为0/45/75°。这是原**有叶叶轴的弧长后半段**，不是 t>.5；三个档使用同一个原 s0，不通过删近端叶重新定义它。同一羽叶两侧均使用相同的正向右手旋转 Q，轴为该根点原 rachis tangent，不按相机挑符号。

健康羽叶原裸轴弧长 .364–.697 m、中位 .486 m；原整 rachis 弧长 4.221–6.912 m、中位5.615 m。s0仍是模型裸轴约定，不是隐藏叶鞘内完整解剖petiole。已有 [Kew 2024描述](https://powo.science.kew.org/taxon/urn:lsid:ipni.org:names:666160-1/general-information)支持“远端半轴约90°扭转”作为研究依据，不代表每枚/每龄叶都应有90°。[NParks](https://www.nparks.gov.sg/florafaunaweb/flora/5/6/5618)的尺寸范围也不能替代当前每个实际上传量的测量。

## 自然直接重算：重力没转，但实体弧长会改变

原实际中脉包含 `F*L*u + side*curl*sin(pi*u) + up*ridge*shape − worldY*droop*u²`。自然方案只以 Q 旋转前三项，再加**原同一世界−Y** sag；B0边缘相对该行中脉的偏移也由Q旋转。根点固定，不整体旋转旧顶点，从而不把重力变为局部侧向。世界下垂构造残差 <3.6e−15 m。

以下统计仅针对9,992片受影响小叶，弧长为**上传 Float32 中脉的分段折线长度**，面积为实际原索引三角形面积：

| 自然方案 | 实际中脉弧长变化 min/max | 弧长变化>1%的片数 | 单片实际三角面积变化 min/max | 全pinna网格面积变化 |
|---|---:|---:|---:|---:|
| 45° | −8.823% / +8.641% | 6,056 | −10.596% / +12.425% | +.00238% |
| 75° | −14.162% / +13.428% | 6,974 | −17.935% / +19.218% | −.00559% |

全冠均值近零只是两侧拉长/缩短互相抵消，不能证明单片尺寸守恒。原因是 `|Q*d_nonGravity + d_gravity|` 一般不等于 `|d_nonGravity + d_gravity|`；保持 L 与 sag参数不是保持真实弧长。自然方案确有合法有限网格，但不满足本轮要隔离的不可伸长约束。

## 独立逐段保长近似

不整体缩放叶片。先从上述自然方案取得每段目标方向 dB，然后逐段令 `PB[j]=PB[j−1]+normalize(dB[j])*length(PA[j]−PA[j−1])`，起点为原上传根点。截面采用 `R=align(Q*TA,TB)*Q` 的 SO(3)传递：保留Q的有向torsion，再以最小旋转对齐中脉切线。宽度、ridge离中脉距离没有被缩放。

**边界：** 世界−Y sag参与目标方向构造，未随roll旋转；但段长投影后，点位与原自然目标的差可以有水平分量，原点位 sag 幅度不再逐点严格相等。这是不可伸长折线的几何投影，**不是重力平衡、梁弯曲、曲率/弯曲能量守恒或弹性求解**。reference_research独立确认应保留此边界。若要求每点保持原 −Y 位移且原段长也严格不变，通常还需改变其他方向/曲率，不能同时把全部条件当作免费不变量。

| 逐段保长方案 | 实际上传弧长变化 min/max | 上传单段相对长度误差最大绝对值 | 单片面积变化 min/max | 偏离自然目标最大距离 |
|---|---:|---:|---:|---:|
| 45° | −.000144% / +.000166% | .001138% | −.1854% / +.2060% | 4.61 cm |
| 75° | −.000184% / +.000144% | .001249% | −.2629% / +.3207% | 7.70 cm |

约束计算在double中逐段长度最大误差 <1e−12 m；表中非零误差主要来自最终上传Float32坐标的独立量化。**保中脉段长不自动严格保叶面积**，后者仍如表另报。全pinna网格面积相对B0分别仅+.000182%、+.000509%，不借此否认单片面积变化。

截面 det(R)−1最大绝对值1.34e−15；Q单位误差与显式TBN均通过。实际 align 最大角45°档11.85°、75°档19.70°，距180°退化很远，本数据没有触发反平行fallback。相邻截面旋转最大分别3.73°/6.21°，没有瞬时符号翻面。若未来扩展其他年龄或角度，仍须给反平行确定fallback，不能把当前未触发推广成所有输入安全。

## 尺寸、端点、TBN与风轴实际影响

- B0健康小叶上传中脉弧长 .435–1.603 m、中位1.123 m；截面最大实际宽度2.60–4.91 cm、中位3.82 cm。均为实际几何量，不把ridge高或贴图频率误称叶宽。
- 四候选叶根最大位移=0；每个根/尖三个重合顶点的分离=0。**叶尖坐标应移动**，否则不是真正改变长轴。逐段保长45°叶尖位移中位20.07 cm/最大36.97 cm；75°中位32.87 cm/最大60.56 cm。原attachment根点、其相互间距、rachis和原裸轴终点都不移动；新叶面交叠是否恶化未由CPU判定。
- 物理截面宽度只受Float32舍入影响，全部候选最大相对差 <.0071%；不是靠加宽实体制造茂盛。
- aLeafAxis更新为Q*原F，与新初始名义方向一致。45°其实际向量转角中位13.75°、最大36.49°；75°中位22.85°、最大59.76°。F包含rachis切向分量，不能把施加torsion角A当作F实际转角。aLeafAxis也不是受重力弯曲后整条中脉的同一切线，不能要求它等于root→tip chord。
- 法线/显式切线重算并正交化。全部425,288个原索引三角形均无新退化；normal、tangent、aLeafAxis有限且单位误差<5.1e−8，N·T最大<4.8e−8，tangent.w没有变化。法线/叶脉框架真实改变，因此相同材质可出现正常高光/薄叶透射变化，不能只看亮度宣称几何更好。
- 索引/UV/颜色/所有其余风属性、aLeafRoot（含原名义L）、树/枝锚点与相位逐byte锁定。未受影响小叶position的32bit word差数=0。0档直接恢复B0对象，也不会改已修centroid colour、深度、motion shader协议或.25标签。

## 几何投影：有可见因果，但全冠总量不足以判好坏

12个方向为elevation5°/25°/65° × azimuth0°/90°/180°/270°。逐段保长45°全pinna网格无自遮挡投影三角面积比约.9954–1.00234；75°约.9903–1.00478。多棵树方位互相抵消，所以总覆盖接近并不意味着每枚羽叶无变化。

为避免挑最有利叶片，脚本在候选比较前选取175枚中**原整轴弧长中位**那一枚，另报其12向投影。45°约.9551–1.2584，75°约.9026–1.4289。它说明有明确的三维投影重分配，也说明75°某些方位会明显变薄；**这些是无自遮挡面积，不是像素coverage、照片真实性或美观分数**。不应要求每方向同时增大，也不应把增大自动判胜。

## 有条件GPU合同：先45°，75°不默认

本轮没有运行时实现授权，不把CPU通过写为已具备真实浏览器候选。若下一轮批准，建议仅新增一个可回滚B1静态变体，默认继续B0；先0/45°逐段保长，75°作为同一算法的强对照。不要同时引入近端去叶、色素提亮、额外噪声、长度/宽度/数量调整或新的风力学。

1. **状态与不变量：** 使用当前封存B0原s0/S与已测定义；白名单仅position/normal/tangent/aLeafAxis。0复用B0全部buffer；新增RNG=0、draw/triangles/attribute数/纹理指令=0。beauty/depth/motion全部读取同一套新aLeafAxis；包围范围使用共同A/B并集，切换重置主/水历史、刷新太阳影图。先GI off固定，再对选中几何重建surfel，不能保留旧GI源。
2. **静态因果：** 同一单羽叶、整冠、时间、太阳/曝光/摄影镜头；先常色unlit，再正常材质；低/中/俯视×四方位与已有HD主镜头。保留单叶羽状连续性与正常三维层次，检查tip位移是否撞入相邻叶/树干。不能仅主镜头更乱/更大就通过。
3. **动态/数值：** 同相位wind0/1.8/5 m/s序列，重新跑motion/depth、根尖重合、centroid/反射全像素finite+nonnegative。normal/SSS改变需在顺/逆光分别观察；不得通过补光或图像模糊掩盖新断层。
4. **实际成本：** 仅静态CPU构建不增加着色指令，但投影/overdraw、影图和反射成本会变化。一个额外QA变体若独立position/normal/tangent/aLeafAxis需 **26,311,584 bytes≈25.09 MiB** CPU typed arrays，若常驻GPU另有同级attribute成本（非实际显存遥测）；不建议同时常驻所有自然/45/75变体。GPU成本必须同机位、天气与像素配置重测。
5. **否决：** 多角度仅局部变美而另处明显成秃缝/乱梳排、损失用户喜欢的完整冠形，或新增风闪/交叠/阴影GI错误，则回到B0。如果45/75均无一致视觉收益，应否定“缺失远端torsion是当前主要假感”的假设；不在本实验追加强度或材质补丁。

**当前建议是“值得一次受控45° GPU对照”，不是“75°已更真实”或“应更新默认”。** 运行时与B4封存保持不变。
