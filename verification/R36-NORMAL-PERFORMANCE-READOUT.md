# R36 普通烟单发演化测量

root 的实际原生 HDR、中档 N8、代表烟路径，从爆后约 2.50→5.5036 s 演化 3.0321 秒：101 帧，**33.31 FPS**；帧间隔均值 29.80 ms、P95 50.40 ms。99 个 GPU 样本均值 **22.89 ms**、P95 **33.258 ms**。这不是固定负载 A/B，也没有证明推荐画质 60 FPS；GPU/CPU 时间重叠，不能相加。

101 帧 CPU wall/submission 分段中，光度准备均值 **11.06 ms**（约38%），water captures **6.52 ms**，main/lens/display **6.57 ms**；烟花物理/音频 **2.65 ms**、其它物理 **1.69 ms**。光度阶段包含完整 source/cluster/bounds 计算、SH 准备与 GL 提交/可能的等待，不能把11.06 ms说成 SH 的独立 GPU 耗时。完整 GPU query 没有细分这三项的硬件时间。

负载在变轻：24 个烟包在前后相同，但 SH 正发光行由 1699 降至 0，最终两眼都为无源 neutral、查询数0。事件仍在生命周期内并不表示还在发光。因此本段平均帧率不能代表早期最亮阶段，也不能当长尾候选相对旧版的速度收益。

实际 +.7/+1.7/+2.5 快照均普通24烟包。两张宽景两眼有源 GPU 路径分别1600/1728行；+2.5近景主眼1703、SH1699，镜眼0是无源中性路由。全部保存数据 GL空、SH effective；暂停快照 SH为reused，不能当作fresh bake计时。

新作者预算为旧1421.292953×16＝22740.687253（非实测cd）。相机增益保持14，宽景 storage P由+.7的10.75到+1.7的11.5；近景为10.75/11.25，stored bound均低于16376。P保护浮点存储，不是偷偷提高相机增益。长尾宽景 adaptive maximumN为16/12，近景33/26，保存估计均无legacy fallback；它解释了长尾有更高核工作可能，但这些CPU估计不能单独证明GPU瓶颈。
