# 验收记录

日期：2026-10-26（Asia/Kuala_Lumpur）。最新一轮镜头、动态天空、同步声音、抗锯齿和性能验收如下。技术检查通过不等于能够在所有距离冒充照片。

## 当前版本：镜头、天空、声音与性能

主视图使用 36 mm 全画幅相机、24–70 mm 焦距和 ±1.5 EV 曝光补偿；可选景深按真实薄透镜弥散圆估算，采用有限采样与深度拒绝。曝光为相对尺度，没有绝对 lux / ISO 校准。实际 UI 极值检查记录了 70 mm 对应 18.26035° 垂直视角、+1.5 EV 对应曝光 2.1496046、f/2.8 景深启用，见 [镜头 UI 读回](lens-ui-extremes.json)。

原摄影 HDR 已退出运行路径。当前天空计算球形大气的 Rayleigh / Mie / 臭氧消光，世界空间三维体积云随风平流与演化；背景、反射、PMREM 环境、地面直射、叶片透光和水体共享太阳与天气。8° 太阳时实际共享 RGB 为 `[1, .62688672, .29563151]`，见 [光照一致性](sunlight-synchronization.json)。白沙地面反弹采用 Hemisphere 近似，环境强度为 .8；旧版本下文的 HDR / .30 / .12 填光配置仅属历史记录。实现细节与云层迭代见 [大气记录](ATMOSPHERE-NOTES.md) 及 [渲染研究](RENDERING-RESEARCH.md)。

渲染链为线性 HDR RT 的 **4× MSAA → 镜头 → SMAA → 单次 ACES / sRGB 输出**。内部尺度小于 1 时实际执行 **FSR 1 EASU + RCAS**，完整尺寸画布不缩小；尺度为 1 时绕过超分。自动分辨率同时监测 GPU 时间与连续帧间隔，保留预热、滞回与恢复等待。没有伪造 DLSS 或 RTX 开关；WebGL 2 的高度场折射和已有平面反射也不称为完整硬件光追。

### 当前实际性能

RTX 4060 Laptop / ANGLE D3D11，细腻画质、MSAA + SMAA、FSR 1、真实环境声开启。每段连续采样约 8–12 秒；最低 fps 按所有完整连续 1 秒窗口的实际 rAF 回调数计算。前四段在最后的小叶局部曲率修正之前采集，第五段来自最终叶形；它们不是相同内部尺度或时段的受控性能对比。原始数组、配置、输入 SHA256 与独立交叉核算见 [性能报告](PERFORMANCE.md)。

## 对照真实照片的修复过程

参照包括真实 Maldives 沙洲、带 2 mm 标尺的珊瑚沙微距和真实椰叶微距；来源及授权见 [素材清单](../assets/SOURCES.md) 和 [微距参照](../assets/palm-reference/SOURCES-AND-REVIEW.md)。

1. **棋盘/格纹焦散。** 早期光线聚焦被两组近乎垂直的正弦波主导，形成规则直线交叉。改为 35 个非公度方向的重力毛细波分量，并按网格分辨率过滤；[旧焦散](08-caustic-buffer.png) 与 [新焦散](09-caustic-spectrum.png) 留存了差异。
2. **白沙像纯白粉状模型。** 随机平铺、颜色混合方差校正、湿度与粗糙度、局部毫米起伏和少量薄碎片逐轮补充细节；降低白位以保留明暗。旧基线为 [18-new-coral-sand.png](18-new-coral-sand.png)。最终材质使用摄影颜色图配合代码生成的颗粒法线、粗糙度和沉积变化，明亮细沙仍有实时近似。
3. **扫描素材中的重复鞋印。** [24-shore-close.png](24-shore-close.png) 暴露了原始细法线包含鞋底/人造压痕，随机平铺无法消除内容本身；后续 `26-shore-v4` 复拍仍发现水下共享颜色层保留鞋印，频段分离也不能可靠修复。最终 v6 移除全部旧 Sand 03 / Aerial Beach 数据，只保留单独检查过的 Sand 02 2K 颜色图（2.14 m），其法线、粗糙度和位移图均不用。[最终岸线](35-shore-final.png)、[干沙近景](36-sand-grain-final.png) 与 [无风对照](37-shore-no-wind.png) 未见旧鞋底轮廓或明显拼接。风浪时出现的长细纹在无风后退成细粒，来自折射映射，仍不能排除部分采样走样。详见 [沙材质开发记录](SAND-MATERIAL-NOTES.md)。
4. **椰叶反射中的黑墨点。** 正确等待画面更新后，NaN 标记与黑点一致。叶尖静态重合顶点具有不同风动权重，风使零面积三角形展开，而其静态法线仍为零。修复移除退化三角形、补齐稳定的正交切线/法线，并同步风变形与透光法线；实际反射缓冲读回已确认非有限像素归零。没有靠压黑或钳制最终水色掩盖输入错误。

最新光照复核中，`28-shadow-map` 确认植物进入阴影图；`29-fill-light-comparison` 指向 HDR 环境之外额外填光过多，使树影不明显。当前将 hemisphere / environment intensity 调整为 0.30 / 0.12。`32-horizon-energy` 将远距遮蔽缺失的辐亮度由深海散射改为低频天空反射，并使用实际 HDR 水平天空衔接大气衰减，减少异常深蓝硬边；这是能量补偿近似，不是精确微面元积分。椰叶独立扭转造成的交织网观感也作了形态调整；[最终近景](30-foliage-refined.png) 与下述连续风动记录已复核。

旧截图保留用于复盘，不应作为最终成品图。调试模式切换后的截图需要等待渲染/合成更新，避免把前一帧误判成新模式结果。
