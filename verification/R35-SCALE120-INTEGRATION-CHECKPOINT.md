# R35：三层烟花的参考展开尺度

2026-10-30。整体目标继续 active；本轮完成尺寸版本的接线和定向检查，照片感及整体性能目标仍未验收。

网页“烟花 → 变化方式”新增 **三层芯 · 120米参考（实验）**。保留蓝外层、绿中层、红内芯和独立金色尾迹，以爆开后2.5秒、达到各点自身峰值光度10%的外层亮点，定义水平最大展开120米。它是明确的作者参考，不是供应商实测曲线，也不保证低角度碰水后仍有完整120米花形。

新版本在三维中统一调整初始径向冲量，保留壳体承载速度、192个亮点、寿命、发光曲线、材料预算及尾迹配方。此实例alpha=2.564724974777301；它不是单独拉宽水平面的扁球。0×调试仍可定义非可见的参考几何，不能当成发光。旧样式的19m/s合同保持，新版本显式使用76m/s家族上界；实际构图按19×本次alpha收紧，并使用当前快门及完整已提交风速范围。

## 定向验证

- 纯尺度模块：作者6/6，独立5/5；原输入校验缺口与修复前报告保留。
- 编译器集成5/5：36组旧输出深度和JSON逐字一致；192个新亮点的曲线、寿命、预算和尾迹保留。
- 物理集成5/5：117个旧事件完全一致；48组角度/旋转新案例及0×对应轨迹通过；实际参考宽度误差小于4.3e-14米。这个浮点误差是程序内部检查精度，不是现实标定精度。
- 连续包围/光学7/7：合法显式高度、实际alpha、未来有界分段风、0–1秒快门，以及227条非空接触局部分段通过。旧shader未改；这些包围不声称覆盖最终Gaussian、景深、bloom或持续烟雾的所有像素。
- 独立烟路由审查5/5：普通模式仍是24团、12个代表root的两次排烟；逐点持续排烟仅QA logical-all。两条路由都消费真实放大后的轨迹，最终模型预算同为20.35，不能称普通模式已全面逐点排烟。
- 保存的实景/还原检查7/7，用户意图29/29精确；原机位、时间、灯、音效设置、面板和暂停恢复。没有还原瞬时海浪、云或历史缓冲相位的主张。

## 实际画面与GPU

同一seed341070普通单发，实际原生1209×1292、中档、8×MSAA、自动HDR，分别停在+.70、+2.50秒。普通模式24团，+.70时1728条光路、41472配对；+2.50时受光40776、遮光40800配对，全部GPU effective，GL无错误。自动取景保留岛和水面空间，近景另行观察。

另一枚相同seed、相同尺度的QA logical-all单发：+.70秒396团/684288配对；+2.50秒1561团，SH受光2652139、SourceT遮光2653700配对，均完整GPU，没有裁掉烟量。ellipsoid投影和tiled64烘焙继承正确。普通与QA释放时程不同、绝对相位不同，因此不是受控像素A/B。

SDR分支在普通+2.50秒同物理时刻单独开启并检查。HDR画面截图是浏览器合成截图，不是原生HDR文件或面板nit实测。没有新增GPU数值oracle、固定单帧计时或连续FPS结论。

## 自评与下一步

展开尺寸已改进，三层颜色和海面倒影可见。近景仍明显是稀疏亮点与短尾迹；烟、云、地表受光过弱。增加逐点烟团后画面仍暗，说明“烟团更多”不能代替辐射能量、持续发光时程和传播模型的修正。本轮照片感不通过。
