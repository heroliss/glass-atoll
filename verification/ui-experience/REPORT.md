# 常用功能与详细设置分层：2026-10-30

本轮完成界面和操作流程；海岛整体的拟真与性能目标尚未完成。

## 已实现

- 左上“海岛时刻”：玻璃晴昼、海上日落、暮色烟花、星河与海四组时间＋机位组合。只应用时间与镜头，不自行燃放烟花；天气、画质和声音保持原设置。
- “选择机位”保留原有缩略图与独立机位选择，补充烟花与离岛、星河视角。单独切机位保留当前时间，并取消组合选中标记。
- 底部常用操作：样式选择、放一枚、随机一发、持续随机、停止后续，及投石、暂停、回到白昼岸边。快捷区与详细烟花设置使用同一份状态和原有发射流程。
- 右侧详细设置保留原有分类与全部控件。快捷入口可直接打开烟花分类。
- 暮色前后提前改用深色界面；移动端展开设置或机位时收起其他常用面板，避免覆盖。保留帧率显示、隐藏界面与恢复入口。

设计采用现有颜色/字体与平面、不透明控制面板。应用了 design-taste-frontend 的应用屏幕流程，抽取 true-black-flat 方向（seed 1602912282）；为全屏3D场景将框架调整为可隐藏的覆盖面板，没有增加新的设计依赖。

## 仍待优化，按优先顺序

1. **完整场景性能**：已有 GPU 数值验证与可选联合作业试点，试点仍默认关闭。需要对持续烟尘、受光、海面倒影与整个渲染帧一起测量，定位 CPU 更新与 GPU 体积过绘；本轮没有密集性能测试，不能宣布稳定60 FPS。
2. **夜间烟花观感**：多层、变色、尾迹等已有基础和实验样式；仍要对照实拍打磨主爆能量、尾迹的细度与连续性、烟/云/地表受光、连续编排及镜头构图。亮度1×仍是场景参考值，未经实物测光标定。
3. **近岸海水**：继续检查定向冲滩/退水的动量感、不同力度的水花与浅水石子可见性、焦散与不同视角的地平线过渡。
4. **整体画面审查**：叶片近远景稳定性、沙粒尺度、云形与大气层次仍需多机位、多时刻复核。UI闭环通过不表示这些效果已验收。
